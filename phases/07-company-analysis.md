# 公司层七步研究流程

| | |
|---|---|
| **输入** | 公司标的（全称 + 代码 + 交易所）+ 可选的核心问题 |
| **输出** | 公司研究报告（11 节）+ 财务底表 + 证据索引 + 审校意见 |
| **前置条件** | 标的已消歧（锁定唯一证券代码）；若涉及行业背景，**优先复用已有行业 SOP** |
| **完成条件** | 通过 `references/research/07-company-financial-checklist.md` 第七节 9 条验收标准 |

> 全程适用 SKILL.md 第〇节约束与 `references/research/06-team-protocol.md` 的通用铁律。

## Step 0: 锁定标的

产出标的卡片：

```markdown
| 字段 | 内容 |
|---|---|
| 公司全称 | |
| 证券代码 + 交易所 | 如 0772.HK / 600415.SH |
| 控股股东 | |
| 财年截止月 | 决定期间的对齐方式 |
| 报告口径日期 | 数据取到哪一天 |
| 核心问题 | 本次要回答什么 |
```

**消歧铁律**：同名的、跨市场多地上市的、曾用名变更的，必须先锁定唯一代码。无法消歧 → 反问，不产出。

## Step 1: 抓原始财报

- 最近 **3 个年度年报** + 最近 **1 期中期报告**
- **必须是 PDF 原文**，不是新闻稿、不是二手解读
- A 股走巨潮，港股走披露易，美股走 SEC EDGAR

```markdown
IF 拿不到 PDF 原文
    THEN 写数据缺口，降级处理
    NOT  不用媒体报道里的数字冒充财报数据
```

## Step 2: 财务拆解（12 项）

按 `references/research/07-company-financial-checklist.md` 第三节逐项提取，**缺项必须写明原因**。

每项格式：`数值 + 单位 ｜ 来源 + 期间 ｜ 会计口径`

示例：
```
35.314 亿元 ｜ 2026 年中期报告·合并利润表 ｜ IFRS，人民币
2.588 亿元  ｜ 2026 年中期业绩公告 ｜ Non-IFRS（剔除一次性及非现金项目）
```

**二手数据一律加前缀 `[二手]`** 并注明机构名与报道日期。

## Step 3: 业务与行业数据

提取运营侧数据：用户数/流量/单价/产能/门店数等。

**口径纪律**（公司层最容易出错的地方）：

| 陷阱 | 处理 |
|---|---|
| 自有平台 vs 全渠道口径 | 分别列出，不混合计算 |
| 含税 vs 不含税收入 | 注明 |
| MAU vs DAU vs 付费用户 | 不互换使用 |
| 累计门店 vs 在营门店 | 见 `tests/expected/case-02` 的口径处理 |

## Step 4: 竞争格局与产业链

**与公司层轨道的接口**：

```markdown
IF 存在该行业的 domain playbook
    THEN 直接调用其「那根杠杆」「跟踪信号表」「口径陷阱表」
    AND  用 Step 2/3 的公司实际数据反向校验行业结论
IF 不存在
    THEN 用六维框架第 3、4 维做局部分析
    AND  在报告中注明「行业结构未做完整拆解，本结论仅基于公司视角」
```

这一复用把两条轨道连起来：**行业轨的面 + 公司轨的点**。

## Step 5: 交叉验证 + 盲区质询

主动找「我这个判断最可能错在哪」：

- 至少列 5 条**尚待验证假设**，每条写明被证伪的条件
- 对每条核心洞察做反向检验：如果这个判断是错的，数据应该长什么样？
- 检查是否有「管理层口径」被当成「披露事实」

适用 `references/research/06-team-protocol.md` 的**四类内容区分**铁律。

## Step 6: 成稿与独立审校

按 11 节结构成稿（模板见 `assets/templates/company-report-template.md`）。

**审校必须与成稿角色分离**，执行 `06-team-protocol.md` 第六节的必检清单，其中：

```
必检项：是否越界输出定价 / 评级 / 择时 / 情绪面 ← 越界即打回
```

审校返回按 **阻断项 / 重要修正 / 可选改进** 三级排序，每个问题指出对应段落 + 原因 + 由谁修正。

## 反馈规则

```
IF Step 0 无法消歧
    THEN 反问用户，不产出

IF Step 1 拿不到财报原文
    THEN 写明缺口并降级；不得用媒体数据补位

IF Step 2 的 12 项中核心 5 项（收入分部/毛利率/OCF/CapEx/ROE或ROIC）缺失 ≥2 项
    THEN 判定本次不适合产出报告
    AND  明确告知用户缺什么、去哪里能补

IF 审校发现阻断项
    THEN 回传对应环节修正
    NOT  由主理人凭经验补写证据
```
