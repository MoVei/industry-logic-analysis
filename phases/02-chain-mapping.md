# Phase 2: 链条绘制与利润归属

| | |
|---|---|
| **输入** | `1-demand.md` |
| **输出** | `2-chain.md`：完整链条图 + 每环节画像 + 成本曲线 + 利润池判定 |
| **前置条件** | Phase 1 完成 |
| **完成条件** | 任取一个环节，能说出「它凭什么拿走这个利润」；主链条假设已被实证修正 |

---

## 步骤 2.1：画出完整链条

从最上游到终端支付，逐环节列出。粒度标准：**相邻两环节之间存在一次真实的市场交易**。

每环节标注四项：

| 字段 | 说明 |
|---|---|
| **集中度** | CR3 / CR5，取不到就写「分散」并注明数据源缺失 |
| **议价权来源** | 技术壁垒 / 资源垄断 / 牌照 / 规模 / 渠道 / 切换成本 —— 必须选一项并举证 |
| **进出价格** | 买入什么价、卖出什么价，形成该环节的价差或加工费 |
| **代表性主体** | 上市公司或龙头，便于后续核数据 |

## 步骤 2.2：校验主链条假设 ★

回到 `0-frame.md` 里抄自分类表的那条假设，用当期实证回答：

- 本行业**真实**的主链条是什么？
- 与假设一致吗？**不一致的地方才是本文的价值**
- 有没有第二条同等重要的机制被假设漏掉了？

**照抄假设不修正，视为重大缺陷。**

## 步骤 2.3：画成本曲线

行业的边际成本分位决定了价格底部在哪。做法：

1. 取各主要生产主体的单位成本（或单位完全成本）
2. 按成本从低到高排序，累加产能，画出累计产能—成本曲线
3. 标出**当前价格落在哪个分位**，判断有多少产能处于现金亏损

> 铝那期用「电价决定的成本曲线分位」讲清楚了为什么价格跌到某位置就有产能退出，这是「锅盖（产能）与座位（需求）」那组类比的数据基础。

## 步骤 2.4：判定利润池

**核心纠偏**：账面营收高 ≠ 留存利润高。必须逐环验证。

判定方法：

- 每环节的**价差 / 加工费**（不是营收）÷ 该环节的必要资本开支 = 该环节的回报率
- 对比上下游回报率，利润池自然浮现
- 交叉验证：用上市公司分业务分部利润表核对该环节的利润率

**必须检查的三种错位**：

| 错位形态 | 表现 |
|---|---|
| 营收大的环节被两头挤压 | 中游加工常见 |
| 账面亏损但现金流为正 | 折旧大的重资产环节 |
| 利润留存上游而定价权在下游 | 资源型行业的常见形态 |

## 步骤 2.5：外部通道校验（可选但推荐）

若存在进口/出口通道，判定它是不是「泄压阀」：

- **是泄压阀**：国内外价差打开后会快速放量，压制国内价格上行空间
- **不是**：存在配额、关税、运输瓶颈、品质错配等限制 —— 必须写清限制是什么

---

## 反馈规则

```
IF 某个环节的集中度或成本数据完全不可得
    THEN 标注数据缺口
    AND  用该环节的上市公司公开数据做单点替代，注明「样本偏差：<方向>」
IF 发现链条比假设多一环或少一环
    THEN 更新主链条，并在最终成稿里写明「流行说法认为 X，实际是 Y」
```
