## 步骤 4.1：三重验证（逐条过滤）

每一条计划写进正文的内容，过三关：

### 第 1 关：事实性

- 能否追溯到 L0 / L1 数据源？（见 `references/sources/data-source-map.md`）
- 是转引吗？转引必须标明原始发布方
- 数据有样本偏差吗？偏差方向必须注明

**不通过判定**：只能用「媒体」「据悉」「市场普遍认为」支撑。

### 第 2 关：相关性

- 这条数据**真的作用于那根杠杆**吗？还是只是同时发生？
- 能否说出作用路径：A → B → C 的每一环？
- 换一个时期，这条关系还成立吗？

**不通过判定**：只有相关性，说不出传导路径。

### 第 3 关：可操作性

- 能否转化成**可观察、有发布频率、有阈值**的指标？
- 能查到该指标的回看历史吗？

**不通过判定**：读者看完无法据此建立自己的观察点 → **删除该条**。

## 步骤 4.2：主链自算律 + 多源闭环律 ★★

> 这两条决定本期结论**要不要降档**。降档 = 无穿透力，是硬约束，不是写法问题。

### 律一：主链自算律

本期核心结论必须有**至少一条**主链，形如：

```
L0 数据 → 本文算术 → 结论
```

要求：

- 正文必须列出**全部输入**，让读者可自行验算
- 第三方测算（沙利文、白皮书、券商、行业调研）**不得作为主链**，只能做交叉印证
- 一条主链都没有 → **核心论点不得进正文**

| 达标 | 不达标 |
|---|---|
| `0.42 元/度 × 13,500 度 = 5,670 元/吨` | `市场约 22% 增长（沙利文测算）` |
| `-241.17 × 3.4542 × 6.7192 = -5,597 元/吨` | `进口份额一度超过 90%（行业转引）` |
| `1.58 × 75.36 × 2.5% = 2.98 欧元/吨` | `国产疫苗价格约为进口的 60—70%（电商口径）` |

### 律二：多源闭环律

承载核心结论的关键量，须有 **≥2 条相互独立**的来源，且量级对得上。

- 独立 = 不同发布主体、不同获取路径（官方统计 / 公司公告 / 具名访谈，可算独立；同一数据的多次转引**不算**）
- 只有单一来源 → 该量**降级为例证**，不得承载核心结论
- 找到多源但互相打架 → 走口径分层（说明各自适用场合），不许挑一个用、其余不提

> 参照系做法：铝篇停槽成本第 4 层用三条独立来源闭环——财新具名访谈 200 万 / EGA 官方 213 万 / 云铝公告 228 万，「对得上了」才敢写。

### 自检问句

> **本文最硬的那个结论，是「算出来的」还是「引来的」？**

答「引来的」→ 回 Phase 2 换取证路径，或回 Phase 0 换题。

## 步骤 4.3：形式校验清单

```
[ ] 每个数字带来源 + 期间 + 口径三件套
[ ] 无「尽量/适当/可以考虑/建议关注/大概率」等模糊词
[ ] 无自谦或粉饰式表述
[ ] 无估算值填补缺口
[ ] 口径不同的数字没有出现在同一句对比中
[ ] 未引用未标注发布方的高频数据
[ ] 第〇节约束全程未违反
[ ] 核心结论有 ≥1 条自算主链，且输入已全部列出
[ ] 承载核心结论的关键量有 ≥2 条独立来源且量级对得上
```

## 步骤 4.4：回路 A 触发判定

```
IF 任一内容未通过三重验证
    THEN 退回 Phase 2 或 Phase 3 重做
    NOT  禁止在本阶段打补丁（补一个数据把它救回来）

IF 核心结论无自算主链（只有第三方测算支撑）
    THEN 退回 Phase 2 换取证路径，或回 Phase 0 换题
    NOT  不许以「该数据为行业通行口径」放行

IF 关键量只有单一来源
    THEN 该量降级为例证，核心结论改写
    NOT  不许让它继续承载主论点
```

打补丁的典型表现：补一条相关性更弱的数据来「证明」同一个结论。**宁可删掉这个论点。**

## 步骤 4.5：数据缺口登记

把找不到的、口径不明的、历史序列断裂的数据项，全部登记进数据缺口表：

| 缺口项 | 缺失原因 | 尝试过的来源 | 对结论的影响 |
|---|---|---|---|

缺口必须在最终正文里原样出现，**不估算填空**。
