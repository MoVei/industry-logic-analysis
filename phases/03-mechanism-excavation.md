## 核心任务：找到那根杠杆

**杠杆定义**：一条本行业独有、能被量化、一动就引起价格或量变动的传导链。

对照既有案例（**只作为「长什么样」的参照，不得抄数据**）：

| 行业 | 那根杠杆 |
|------|---------|
| 铜 | TC/RC 冶炼加工费倒挂 —— 矿端与冶炼端争夺同一块利润 |
| 生猪 | 能繁母猪 → 商品猪出栏的 10—13 个月生物时滞 |
| 天然气 | 三地气价价差与顺价机制 |
| 铝 | 电价决定的成本曲线分位 |

### 杠杆的准入四问（四条全中才算数）

1. **独有性**：换一个行业，这条链还成立吗？成立 → 不够格
2. **可量化**：能说出「X 变动 1%，引起 Y 变动多少」或「传导需要 N 个月」吗？说不出 → 不够格
3. **当期性**：它正在被触发或正走向触发吗？完全休眠 → 留到下期
4. **必要性（反事实）★**：写出「**若这根杠杆不存在，本期的主现象就不会发生**」的反事实陈述。写不出 → 它不是杠杆，只是相关项

**第 4 问的写法参照**：不要写「这根杠杆很重要」，要写反事实推演——「只有第一层，会……；只有第二层，会……；缺了第 N 层，本期现象不成立」。逐层剥离，证明每一层都不可省。

### 双层结构要求 ★（只答第一层判为「半根杠杆」）

杠杆必须回答两件事，缺一不可：

| 层 | 回答什么 | 不答的后果 |
|---|---|---|
| **第一层：机制层** | 谁在赚钱 / 份额怎么变的 / 价格怎么传导的 | — |
| **第二层：不响应层** | **为什么这个格局没有被竞争抹平**——进入壁垒、沉没成本、产能约束、切换成本、监管闸门，任选其一是本行业真正起作用的那个 | 只解释「现象发生了」，解释不了「为何持续」，稀缺性论证不闭合 |

> 典型反例：只说「某资源稀缺所以赚钱」是半根杠杆。必须补上「为什么高利润没有引来新增供给把利润抹平」——铝篇的答案是产能红线焊死 + 停槽沉没成本极高，这才是完整的一根。

**只有第一层 → 回 Phase 2 补第二层，不许以「壁垒较高」这类无机制的短语结案。**

> 模式库 `references/research/04-mechanism-pattern-library.md` 用于**识别**，不用于**套用**。把某行业的机制直接搬到另一个行业是重大缺陷。

## 步骤 3.1：量化传导方向与时长

- 方向：上游变动 → 下游哪一端先响应
- 时长：给出区间而非单点，并做敏感性测试（如 10 / 12 / 13 个月三档分别得出什么结论）
- **必须说明为什么会超调**：时滞 + 信息不对称 + 参与者同质行为，共同构成超调

## 步骤 3.2：列出全部对冲变量 ★

这是「表观与实质之差」的来源。逐个找出会**稀释或放大**该传导的变量，每个都要给量级。

生猪那期识别出三层对冲，把表观 −10.7% 稀释到实际 −7.6%：

| 对冲变量 | 量级 | 作用方向 |
|---|---|---|
| PSY/MSY 效率提升 | +1.73% | 稀释去化效果 |
| 出栏均重提升 | +1.77% | 稀释去化效果 |
| 冻品库容投放 | 视库容而定 | 短期放大供给 |

**清单必须穷举到「头三项能解释 ≥80% 的差额」为止**，否则继续找。

## 步骤 3.3：多层乘法分解 + 反向验证 ★★

把现象拆成可相乘的几层，每层与官方数据闭合：

```
实际供给变动 = 表观存栏变动 × (1 + 效率变动) × (1 + 均重变动) × (1 ± 库存变动)
```

然后**反向验证**：用官方公布的最终值（如出栏量、产量）核对自己的分解结果。

> 生猪：自算出栏 +1.41% vs 官方 +1.4%；自算猪肉产量 +3.20% vs 官方 +3.2% —— 闭合到小数点后一位，才敢把这套分解写进正文。

**闭合不上不许进正文。** 差在哪一层，就回去查那一层的数据源或口径。

## 步骤 3.4：找历史实证区间

至少 1 个完整历史案例，含具体数字，用于回测该机制：

- 起止时间、起始读数、传导过程、最终读数
- **明确写出这次回测是「验证了机制」还是「暴露了机制的边界」**

补不出历史区间 → 在本份产出中标明「机制未经历史回测」，且 SOP 定级上限为 Draft。

## 步骤 3.5：找倒置与反例

回答：**什么时候这根杠杆会失灵？**

- 至少列 2 个失效情景
- 每个情景配一个可观测的触发条件（为 Phase 5 的反证清单准备素材）

## 反馈规则

```
IF 杠杆准入四问不全中（尤其第 4 问必要性写不出反事实）
    THEN 回到 Phase 2，换环节或换角度重找
    NOT  不许用「此外还有 X、Y、Z 等因素影响」糊过去

IF 杠杆只有机制层、缺不响应层（半根杠杆）
    THEN 回 Phase 2 补「为什么没被竞争抹平」的实证
    NOT  不许用「壁垒较高 / 格局稳定」这类无机制短语结案

IF 多层乘法分解与官方数据闭合不上（偏离 >5%）
    THEN 逐层回查数据源与口径
    NOT  不许调整系数凑结果

IF 找不到任何历史实证区间
    THEN 标注「未回测」
    AND  SOP 定级封顶 Draft
```
