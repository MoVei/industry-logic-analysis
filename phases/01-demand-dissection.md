# Phase 1: 需求端解剖

| | |
|---|---|
| **输入** | `0-frame.md` |
| **输出** | `1-demand.md`：需求四问答案 + 替代效应量价对照 + 口径分离表 |
| **前置条件** | Phase 0 完成，边界已确定 |
| **完成条件** | 能说清「需求为什么变」而不是「需求在变」；至少完成 1 组替代效应对照 |

> 这是最常被跳过或草草带过的阶段，也是最能拉开差距的阶段。跳不过去。

---

## 步骤 1.1：需求四问（逐条回答，不许合并）

1. **谁付钱** —— 终端付款人是谁，中间有无代付方。付款人与使用人分离时必须分别分析（如处方药：患者用、医保付）
2. **为什么现在付** —— 触发购买的直接动因，与长期背景分开
3. **支付能力由什么驱动** —— 找到付款人的收入/现金流来源，而不是笼统写「消费能力」
4. **不买会买什么** —— 替代品清单 + **各自的量价数据**

第 4 问是本阶段的产出重点，进步骤 1.2。

## 步骤 1.2：替代效应量价对照 ★

这是识别真假需求变化最锋利的工具。做法：

对每一个替代品，同时取**产量/销量（量）**与**价格（价）**，两者交叉判断：

| 替代品量的变化 | 替代品价的变化 | 判定 |
|---|---|---|
| ↑ | → 或 ↑ | **真实的替代需求转移**（买方真的转去买它了） |
| ↑ | ↓ | 可能是替代品自身供给过剩压价，**不是需求转移** |
| → 或 ↓ | ↓ | 替代品自身在收缩，与本行业无关 |

> 生猪那期靠「禽肉产量 +9.3% 而禽肉价格没有跌」这一条排除了「猪肉被禽肉替代」的流行解释，直接把主线推到供给端，这是全文成立的前提。

没有量价两个维度，就不能下替代结论。只写「受到替代品冲击」是无效分析。

## 步骤 1.3：口径分离（制度化）

以下三组混淆是数据丑闻的主要来源，逐项检查并明确标注：

| 混淆类型 | 典型陷阱 | 处理 |
|---|---|---|
| 时点 vs 期间 | 存栏（时点数）与出栏（期间数） | 写明「两者不可比较」 |
| 家庭 vs 全口径 | 居民人均消费与表观消费量 | 分别列出，不混合计算 |
| 平均 vs 头部 | 全国平均利润率与上市企业均值 | 注明样本范围与偏差方向 |

口径混淆一旦发生，后续所有推导都会错位，且难以在成稿阶段补救。

## 步骤 1.4：需求规模与增速

- 取**至少两个独立来源**交叉（如国家统计局 + 行业协会）
- 增速必须写清基期，避免季节性误导
- 如果需求端本身基本稳定（很多行业的真实情况），明确写「需求端不构成当期主要变量」，把资源让给 Phase 3 —— **这是诚实，不是偷懒**

## 步骤 1.5：写出需求驱动三因子

把需求变动拆成可乘的三层：

```
需求总量 ≈ 人口/客户基数 × 渗透率/单客频次 × 单次用量/客单价
```

每层配一个数。拆不出来的层写「数据缺口」，不许留空或用行业平均值补。

---

## 反馈规则

```
IF 需求端查完发现「需求几乎无变化」
    THEN 在 1-demand.md 首页顶格写明这一点
    AND  Phase 3 的资源全部投向供给与传导机制
IF 数据不可得导致某层拆不出来
    THEN 写入数据缺口表，Phase 5 的正文里同样要出现这个缺口
```
