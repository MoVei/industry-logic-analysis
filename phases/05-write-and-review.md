# Phase 5: 成稿与审校

| | |
|---|---|
| **输入** | `4-verification.md` 通过的全部内容 |
| **输出** | 五件套：`数据表.md`、`证据索引.md`、`领域分析.md`、`正文.md`、`审校意见.md` |
| **前置条件** | Phase 4 全部通过 |
| **完成条件** | 五件套齐全；审校至少挑出 3 个具体问题；跟踪信号表与反证清单完整 |

---

## 步骤 5.1：严守五件套产出顺序

```
数据表 → 证据索引 → 领域分析 → 审校 → 正文
```

**正文最后一个写。** 这条顺序的作用是防止正文里出现未经登记的数字。

> **硬约束：禁止正文出现数据表里没有的数字。**

每个结论在正文里挂证据编号，编号对应 `证据索引.md`。

## 步骤 5.2：按选择的形态成稿

| 形态 | 篇幅 | 模板 |
|------|------|------|
| **longform（默认）** | ≥3000 字 | `assets/templates/longform-template.md` |
| report | ≥4000 字 | `assets/templates/report-template.md` |
| brief | 800—1200 字 | `assets/templates/brief-template.md` |

写作风格逐条对照 `references/research/05-writing-dna.md`。

## 步骤 5.3：必产出的三张表

### ① 跟踪信号表（缺一不可）

| 字段 | 说明 |
|---|---|
| 指标名 | 具体名称 |
| 谁发布 | 精确到机构与报表名 |
| 频率 | 月/季/周 |
| 当前读数 | 带期间 |
| 阈值与含义 | 到什么数值意味着什么 |
| 信号桶 | A / B / C |

共振规则必须写清：**几桶同时亮起才算确认**。

### ② 反证清单

逐条写「什么情况下我错了」，每项配：
- 可观测的触发指标 + 阈值
- 触发后本文哪个结论失效

### ③ 数据缺口表

与 Phase 4.4 登记的一致，原样出现在正文。

## 步骤 5.4：独立审校

审校必须**换一个视角重跑一遍**，而不是复读自己的结论。执行 `references/decisions.md` 中 D9 定义的审校角色。

强制要求：

```
审校必须挑出至少 3 个具体问题
挑不出 = 审校没做
```

每个问题必须指明：位置 + 问题性质 + 具体怎么改。写「整体不错，细节可再打磨」这类无效反馈视为未完成。

### 回路 B

```
IF 审校判定「缺历史实证」或「无独家洞察」
    THEN 退回 Phase 3 重新考古
```

## 步骤 5.5：措辞终检

对 `正文.md` 全量扫描（段落 + 表格单元格），按 SKILL.md A3 的红线清单执行：

- 自谦/粉饰/让步类表述 → **直接删除该句**，不改写为委婉说法
- 模糊词 → 替换为具体标准或删除
- 术语首次出现 → 补白话解释

完成后附上组合计数（匹配项数 = 0 才算通过），抽查不算。
