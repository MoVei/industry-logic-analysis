# Phase 5: 成稿与审校

| | |
|---|---|
| **输入** | `4-verification.md` 通过的全部内容 |
| **输出** | 五件套：`数据表.md`、`证据索引.md`、`领域分析.md`、`正文.md`、`审校意见.md` |
| **前置条件** | Phase 4 全部通过 |
| **完成条件** | 五件套齐全；审校至少挑出 3 个具体问题；跟踪信号表与反证清单完整；**可读性门禁通过（正文编号 0、四类标签 0、超线 ≤3 项）** |

> **读者**：没读过这个行业任何一份研究报告、但有生活常识和初中算术的成年人。
> 不是同行，不是审校员，也不是下一个会话的自己。后两者要的东西放底稿和附录，不放正文。
> 完整规范见 [`references/research/08-readability-laypeople.md`](../references/research/08-readability-laypeople.md)。

---

## 步骤 5.1：严守五件套产出顺序

```
数据表 → 证据索引 → 领域分析 → 审校 → 正文
```

**正文最后一个写。** 这条顺序的作用是防止正文里出现未经登记的数字。

> **硬约束：禁止正文出现数据表里没有的数字。**

每个数字都来自数据表；但**编号不进正文**（见 5.3），正文里只写「谁说的 + 什么时候」。

## 步骤 5.2：写正文前先口述一遍（新，v1.5.0）

顺序不变，变的是写正文时手边放什么。

```
① 记数：打开数据表与领域分析的结论段，只记 5—8 个关键数，然后合上
② 口述：把这一节讲一遍，像对着一个人讲；允许粗糙、允许没出处，不许查表、不许写表
③ 核数：拿数据表逐个核对；对不上的改数字，不许改话去迁就数字
④ 补出处：句末补「机构 + 期间」，编号只进附录对照表
⑤ 量一次：跑 readability-check.py，超线的段落重写那几节，别全局修剪
```

**为什么不能边看表边写**：视线落在表格行上，一段就自然对应一组行——这是长段落的直接成因。段落长度中位数从 40—69 字涨到 121—183 字，主要不是文笔问题，是视线落点问题。

口述这一遍不进文件，不占五件套名额。它是写正文前的准备动作。

## 步骤 5.3：双轨引用

正文只写**谁说的 + 什么时候**；底稿编号留在附录。

| | 正文（读者看） | 附录 / 底稿（审校看） |
|---|---|---|
| 出处 | `（IGO 季报，2026Q3）`、`（国家统计局，2026Q3 末）` | `D501` |
| 四类内容 | 用措辞说清：「公司在三季报里写的」「管理层在电话会上说」「有机构算过」「按上面的数自己算」 | `【事实】`/`【管理层口径】`/`【外部】`/`【推演】` |
| 关键换算 | 算式直接写在正文（三行以内） | 换算链与输入明细 |

**正文禁止出现任何编号形态**：`D501`、`C504`、`F12`、`[1]`、`①`。也禁止出现方括号标签。这两项是脚本检查的一票否决项。

四类内容必须区分的红线不变（A3），只是把「贴标签」换成「说清是谁说的」——读者读完那句，要知道这话能不能当事实用。

## 步骤 5.4：按选择的形态成稿

| 形态 | 篇幅 | 模板 |
|------|------|------|
| **longform（默认）** | ≥3000 字 | `assets/templates/longform-template.md` |
| report | ≥4000 字 | `assets/templates/report-template.md` |
| brief | 800—1200 字 | `assets/templates/brief-template.md` |

写作风格逐条对照 `references/research/05-writing-dna.md`；
版面与声部对照 `references/research/08-readability-laypeople.md` §4—§6。

开篇三条硬要求：前 700 字数字 ≤24 个、不放表、不放编号；第一张表不早于第 600 字；顺序为「物件/账单 → 矛盾 → 这道算术题」。

## 步骤 5.5：必产出的四张表

### ① 跟踪信号表（缺一不可）

| 字段 | 说明 |
|---|---|
| 指标名 | 具体名称 |
| 谁发布 | 精确到机构与报表名 |
| 频率 | 月/季/周 |
| 当前读数 | 带期间 |
| 阈值与含义 | 到什么数值意味着什么 |
| 信号桶 | A / B / C |

共振规则必须写清：**几桶同时亮起才算确认**。

### ② 反证清单

逐条写「什么情况下我错了」，每项配：
- 可观测的触发指标 + 阈值
- 触发后本文哪个结论失效

### ③ 数据缺口表

与 Phase 4.4 登记的一致，原样出现在正文。

### ④ 数字与出处对照表（文末附录，新增）

| 正文位置 | 文中写法 | 编号 | 来源 + 期间 + 口径 |
|---|---|---|---|
| 四·第 2 段 | IGO 季报，2026Q3 | D501 | IGO《September 2026 Quarterly Activities Report》，2026-10-29 发布，2026Q3，C1 现金成本口径 |

- 正文出现一个数字，附录对应一行，**不得遗漏**。
- 审校回查路径：正文 → 附录 → 编号 → 数据表行，一步不少。
- 附录不计入正文字数，不参与可读性统计。

## 步骤 5.6：可读性门禁（新，v1.5.0）

```
python scripts/helpers/readability-check.py 产出/<行业>/NN-*/正文.md
```

| 一票否决 | 门槛 |
|---|---|
| 正文底稿编号 | 0 处 |
| 四类内容标签 | 0 处 |

| 软指标（超线 ≤3 项为过） | 门槛 |
|---|---|
| 段落长度中位数 | ≤90 字 |
| 单句成段占比 | ≥30% |
| 平均句长 | ≤55 字 |
| 超 60 字句占比 | ≤35% |
| 多括注段落占比 | ≤25% |
| 旁白密度 | ≥0.6 处/千字 |
| 设问 | ≥2 个 |
| 开篇前 700 字数字 | ≤24 个 |
| 第一张表位置 | ≥600 字 |

超线时的处理：**重写超线的那几节**，不做全局修剪。指标是结果，不是指令——盯着「段长不超过 90 字」去砍句，会写出被切断的句子。

自检三问（不记阈值也能用）：

1. 这段能不能不看材料、对着一个人念出来？
2. 把括注和编号全删掉再读，句子悬空了吗？悬空说明括注是承重墙，要抬进主干。
3. 读完这段，能用一句话说出它讲了什么吗？说不出就是一段塞了两个意思。

## 步骤 5.7：独立审校

审校必须**换一个视角重跑一遍**，而不是复读自己的结论。执行 `references/decisions.md` 中 D9 定义的审校角色。

强制要求：

```
审校必须挑出至少 3 个具体问题
挑不出 = 审校没做
```

每个问题必须指明：位置 + 问题性质 + 具体怎么改。写「整体不错，细节可再打磨」这类无效反馈视为未完成。

审校必查三项（v1.5.0 起）：

- 附录对照表是否覆盖正文全部数字，抽查 5 行能否回查到数据表
- 正文是否残留编号或方括号标签
- 四类内容是否仍能分辨（读了句子知道是谁说的）

### 回路 B

```
IF 审校判定「缺历史实证」或「无独家洞察」
    THEN 退回 Phase 3 重新考古

IF 可读性门禁一票否决失败
    THEN 退回 5.2 重做口述稿，不许只在句子上做删减
```

## 步骤 5.8：措辞终检

对 `正文.md` 全量扫描（段落 + 表格单元格），按 SKILL.md A3 的红线清单执行：

- 自谦/粉饰/让步类表述 → **直接删除该句**，不改写为委婉说法
- 模糊词 → 替换为具体标准或删除
- 术语首次出现 → 补白话解释

完成后附上组合计数（匹配项数 = 0 才算通过），抽查不算。
