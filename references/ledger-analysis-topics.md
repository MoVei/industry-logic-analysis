## 字段说明

| 字段 | 填写要求 |
|---|---|
| 大类 | A—G（见 `research/01-industry-taxonomy.md`） |
| 细分标的 | 边界可界定的具体标的，不写「新能源」这类词 |
| 期号 | NN |
| 生活入口 | 本文第一段用哪个生活场景切进去 |
| 切入角度（那根杠杆） | **必须是本行业独有的量化传导链** |
| 核心案例 | 用于回测机制的历史区间（含起止时间） |
| 关键数据（含期间） | 3—5 项最核心的数据及其期间 |
| SOP 是否已沉淀 | 是 / 否 |
| SOP 定级 | Draft / Verified / Authoritative / — |
| 验证结论 | 本期的机制判断当前是否有效，有无新反例 |

---

## 间隔规则

| 层级 | 最小间隔 |
|---|---|
| 同一**二级**细分行业 | ≥6 期 |
| 同一**三级**角度或同一根杠杆 | ≥12 期 |
| 同一生活入口场景 | 不得复用 |

**三级优先于二级**：同一二级行业可以再分析，但必须换三级角度。
