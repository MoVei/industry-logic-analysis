## 1. 那根杠杆 ★

**这一行的供给不由价格决定。同一个下跌信号，三个环节给出三种响应函数，没有一种是减产：矿端降价、冶炼增产、渠道清库存。**

传导链：

```
价格下跌（2026 年内回撤 −56.8% 至 −57.9%）
  → 矿端以更快的降价响应（10 月精矿 −31.35% 快于电碳 −29.62%；单周 −14.3% 对 −3.5%）
  → 冶炼端以增产响应（开工率 +0.4pct、月产量 +2.5% 且高于预期、外采矿库存 +4.6 万吨）
  → 只有渠道以清库存响应（8 周 −37,618 吨，占总去库 91.84%；上游 −133 吨）
  → 「亏损→减产→价格回升」的自反身性刹车失灵
  → 价格的下行不被任何一环的生产决策吸收，只能在渠道与期货端释放（基差 −2,860 → +5,700，仓单 53,083 → 17,121 吨）
```

**量化时长与系数**：
- 矿端退出/复产的时钟是**行政审批**，不是成本：枧下窝 2025-08-09 矿证到期停产 → 2026-10-30 环评批复（宜环审〔2026〕53 号），**14.7 个月**；新采矿证有效期至 2047-11-27。
- 冶炼端的开关由**物流与设备**触发，不由价格触发：中矿 6.5 万吨＝原料运输错配（公告 2026-050，8 月已复产）；九岭＝焙烧窑故障（影响 4,000 吨）。
- 矿冶之间的利润分配不固定，取决于并存的两类公式：泰利森按四家机构**精矿指数月定价**；天华长协公式**挂钩盐价并约定利润分享比例**；PLS—Canmax 与雅化 MGLIT 均设 **SC6 1,000 美元/吨地板价**。
- 名义产能利用率 **54.83%**（97.6 ÷ 178 万吨，协会口径自算）；新增规划 42 万吨/年（= 2025 年产量的 43.0%），但安泰科自述新线 **3—6 个月爬坡、2026 年内难以满负荷**。
- 仓单时钟：基准品须生产日期 **60 天以内**、替代品 240 天以内；**每年 3／7／11 月最后一个交易日前全部注销**。

**超调为什么必然发生**：① 库存按货权可拆成四段，而市场只引用总量 → 信号本身被误读；② 所有渠道参与者看同一套 SMM/Mysteel 周度数与同一个主力合约，退出决策彼此参照；③ 转换器不刹车（亏损时开工率仍升）；④ 仓单规则使近月可交割货源结构性收缩，与现货积压并存，诱发基差走扩并被读成「现货紧张」。

**本杠杆的适用边界（不得写成普适律）**：
- 证照时钟目前只有**枧下窝一个可完整回溯的个案**，且存在反例（永兴化山矿矿种变更未结但「本年度采矿量已接近年度生产目标」）。
- 「以加工费确认收入」只对**代工/客供料**成立（盛新净额法、调研云母代工厂加工费 3.6—3.7 万元/吨、单吨净利约 2,000 元、开工率约 95%）；总额法冶炼厂的毛利率确实随盐价剧变（江特 5.91%、赣锋 27.41% 且 Q3 降至 20.17%）。
- 「只有贸易商响应价格」不成立——矿端以降价响应。准确表述是**只有贸易商以减货响应**。

**回测定性：验证了机制的一半，暴露了另一半的边界。**
- 验证：① 停产原因逐条为证照/物流/设备，无一为价格；② 去库主体在渠道而非生产端（三源同向）；③ 价格与利润可同时反向。
- 边界：① 货权口径序列仅 2026-04-30 后存在 → **去库归因只有 8 周证据窗口**；② 矿端让利与合同地板价互斥，触界后本文因果链需重验；③ 雅保 Kemerton 已退出 → 「转换器不退出」限于中国外购料冶炼，不适用于西方一体化转化资产。

## 5. 常见误读与纠错

| ❌ 流行说法 | ✅ 正解 |
|---|---|
| 持续去库＝供给收紧，价格有支撑 | 去库的 91.84%—98.85% 来自贸易商，上游 −133 吨（近零）／+3,200 吨／+5,012 吨（三源）。这是**渠道去杠杆**，给的是卖压 |
| 锂价腰斩，行业重回亏损 | 腰斩是**年内回撤 −56.8% 至 −57.9%**；前三季均价**同比 +121.3%**。把环比回撤当水平同比是这一推论的全部来源 |
| 冶炼亏损会逼出产能出清，价格因此见底 | 亏损中开工率 +0.4pct、月产量 +2.5% 且高于预期、外采矿库存 +4.6 万吨；本次未检索到 2026 年境内任何永久退出。真正的转化产能退出发生在西澳 |
| 停产的江西锂矿是因价格跌穿成本 | 三条可核停产原因＝证照（枧下窝）、物流（中矿）、设备（九岭）。且「江西四矿停产换证」被公司口径顶回（化山矿采量接近年度目标） |
| 矿端暴利，亏损全落在冶炼 | 10 月精矿跌幅大于盐价，比值月让 2.46%、单周让 11.2%，冶炼亏损一周内收窄 56.4%。矿端在让利——但让利有 1,000 美元/吨的地板 |
| 氢氧化锂贴水碳酸锂是新出现的翻转 | 2024-01 至 2026-07 整段在零轴下方；**翻转发生在 2023Q3—2024Q1**（2023-04 曾溢价 97,500 元/吨）。它是存量状态，不是当期信号 |
| 中国产能 178 万吨＝有效供给 | 名义利用率 54.83%；新线 3—6 个月爬坡、2026 年内难以满负荷；「有效运行产能」无机构序列（缺口） |
| 电车卖不动，所以锂不行 | 电池产量 +63.4% 而装车 +16.7%，装车率自算 31.44%；差额去储能（+111.8%）与出口（+51.6%）。锂的需求看电池产量，不看乘用车销量 |
| 高毛利环节就是利润池 | 天齐同一年内矿端毛利率 52.88% 对化合物端 28.59%（1.85 倍），海外转化环节 3.21%；藏格碳酸锂毛利率 73.32% 但其归母 77.06% 来自巨龙铜投资收益 |

## 6. 口径陷阱表

| 不可比较对 | 原因 | 处理 |
|---|---|---|
| 库存**货权口径** 对 **物理环节口径** | SMM 按货权、Mysteel 按环节；总量 12.8 万吨级 对 9.6 万吨级 | 只作方向级印证，占比不跨机构比较 |
| 库存时点 对 产量期间 | 时点相减才得期间变动 | 一律「期末 − 期初」，分项与总量双向闭合 |
| **环比回撤** 对 **同比均价** | 一为高点到低点，一为两期均价比 | 并列写并各标期间，不相减 |
| **含税售价** 对 **不含税成本** | 藏格等披露混用 | 用 13% 增值税显式还原后再算毛利率；还原式非独立验证 |
| 协会产量 对 SMM/Mysteel 产量 | 渣提锂、锂盐互转是否计入 | 同一恒等式内只用同源值；跨源只作量级核对 |
| 月初／月末价 对 季度均价 | 两点 对 全期均值 | 标明「时点对」，不当均价用 |
| 精矿指数 对 精矿区间报价 对 周均价 | 同日多值 | 只取标名指数并标机构 |
| SMM 升贴水 对 富宝升贴水 | 4,600 对 1,175 | 分列，不相减 |
| 联盟发布值 对 崔东树个人推导 | 装车率等系个人计算 | 一律回联盟原值自算 |
| 名义产能 对 有效产能 | 无有效产能序列 | 用利用率 + 爬坡周期两条约束表述 |
| 代工净额法收入 对 自购料总额法收入 | 同一「收入」不同含义 | 不比规模，只比毛利率结构 |
| 公司披露毛利率变动 对 本文还原变动 | 基期含税构造未注明 | 以自算值为主，披露值并列 |

## 7. 跟踪信号表

指标 / 发布方 / 频率 / 阈值 / 桶（完整表见 `产出/碳酸锂/第03期/正文.md` 第九节，共 14 行）：

- **A 桶（供给是否真在收缩）**：贸易商占比是否降至 <50%；上游库存是否连续 4 周去库 >3,000 吨/周；开工率是否连续 4 周下行；外采矿库存是否转负；SC6 是否触及 1,000 美元地板；**是否出现第一例永久关停/产线转让**
- **B 桶（利润与结构）**：精矿／盐价比值是否反弹 ≥10%；电氢对电碳价差是否上穿零轴；装车率是否回升 >40%；铁锂价格是否连续回升而锂价仍跌
- **C 桶（制度与外部）**：枧下窝是否出料；仓单在 3/7/11 月末注销后是否重新累积；注册品牌是否 ≥3 家；进口量同比是否转负

**共振规则**：A 桶 ≥2 项 **且** B 桶 ≥1 项同时亮起 → 才确认「供给开始收缩」。单项只作预警。**基差走强与仓单下降单独出现时不构成「现货紧张」**——它们是 60/240 天与三档强制注销的规则产物。C 桶「注册品牌 ≥3 家」或细则改动单独亮起 → 本 SOP 前提失效，回 Phase 3。

## 8. 失效条款 ★

**F1（强制）** 若 SMM《碳酸锂周度库存（货权口径）》或 Mysteel 207 家样本库存停更、变更口径或调整样本框 → 本 SOP 自动降为 Draft，30 日内寻找替代源（路径：以百川工厂库存 + 广期所仓单 + 上市公司存货跌价三条拼出上游侧代理）。
*现状注记：SMM 已于 2026-09-03 扩容并自述新旧不可比，F1 的前半条件已在事实上发生，故本 SOP 定级封顶 Draft。*

**F2（强制）** 若连续 2 期出现「上游库存随总库存同步去化且占比 >50%」，或任一公司在**公告**中把停产原因写为价格/亏损 → **主链条作废，回到 Phase 3 重新考古**。

**F3（行业特性）** 若出现下列任一，相关章节暂停适用：
- SC6 精矿价格触及 1,000 美元/吨承购地板 → 第 2 节②号「矿端让利」对冲失效，压缩转回冶炼端，须重估冶炼开工的可持续性；
- 广期所修改仓单有效期或取消 3/7/11 月强制注销 → 第 1 节「仓单时钟」与第 7 节 C 桶阈值全部改写；
- 中国出现首例锂盐冶炼产能永久关停/转让 → 成本曲线分位法回归，第 6 节「最右端不在中国」作废。

**F4（本 SOP 特有）** 若国家统计局或有色协会开始**单独、按季发布碳酸锂产量与分环节库存**（即出现 L0/L1 级最终值）→ 本文所有「定义差只能作量级核对」的限定作废，须重建供给-消费恒等式并回测第 4 节区间。
