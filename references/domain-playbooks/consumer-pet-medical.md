## 1. 那根杠杆 ★

**供给开关不是「批文放没放开」，而是「进来的是哪一种持证资格」。**

传导链：

```
应急评价通道开启（非关键资料可暂不提供）
   → 临时兽药产品批准文号（兽药临字，有效期 ≤2 年）批量上市
   → 名义进入者远大于可长期交付者（16 家次对 1 款正式持证国产）
   → 批签发逐批再筛（未通过不得上市）
   → 份额可以跃升（次数口径 2024 年 72.09% → 2025 年 84.24%）
   → 但毛利塌得很慢（持证方分部毛利率 59.47% → 64.37%）
```

**量化时长**：
- 注册端法定净时钟 190 个工作日；另有 232 个工作日可被暂停（补资料 132 + 现场核查 40 + 标准确认 60）
- 企业一手实测：提交临床试验申请到取得产品批准文号 **6 年以上**（两家不同主体独立表述）
- 上市端复核检验：生物制品 ≤120 个工作日；中监所评审 ≤30 个工作日；法定办结 90 个工作日
- 批签发：审查核对 5 个工作日 + 抽验 45 个工作日（2026-06-01 新程序）
- **文号寿命：临字 ≤2 年、生字 5 年**；按 11 款可售加权的资格寿命 **2.27 年 = 正式通道的 45.45%**
- 监测期：二类 4 年、三类 3 年、四类可「/」不设 → 以 (2026)70 号为例，他人最早约 2029-07 可申请同品种

**敏感性（三档）**：若审评暂停项被取消且净时钟压到 120 工作日 → 常规注册通道变快，临字通道的相对优势下降；若临字批量换发生字（≥6 款）→ 加权资格寿命跳到 5 年，本 SOP 主链条失效；若出现监测期标注「/」→ 排他基础消失。

**为什么必然超调**：供给开关离散（一次公告发一批）+ 参与者拿同质信号 + 应急评价在资料完整性上被明文降低 → 所有想快进的企业挤同一道门，而通行证只有两年。

## 2. 完整对冲变量清单 ★

| 对冲变量 | 量级 / 作用 | 方向 |
|---|---|---|
| ① 文号种类（临字 ≤2 年 vs 生字 5 年） | 11 款可售中 10 款临字；加权寿命 2.27 年 | **稀释**价格战烈度：短期产权 → 短期回收要求 → 抬价优先于压价 |
| ② 产能资本开支未跟进 | 宠物制剂生产线募投被终止，6,052.56 万元改投别品种 | **稀释**新增供给的可持续性 |
| ③ 监测期法律排他 | 三类 3 年 / 二类 4 年，期内不批准他人生产**或者进口** | **稀释**后来者进入速度 |
| ④ 毒株组合与证书各自独立 | 六张证书分属不同单位与不同株组合 | **放大**差异化，削弱同质比价 |
| ⑤ 渠道锁定与关联采购 | 终端头部连锁向单一持证方采购占总采购 22.5% | **放大**头部持证者份额 |
| ⑥ 逐批批签发的再筛除 | 2024 年 12 家企业仅 129 批次（强度约 12.6 批次/款·年） | **稀释**名义企业数到实际可售量 |
| ⑦ 进口通道关闭 | 兽用疫苗进口量 2021→2025 −37.81%，外资持证身份迁入境内 | **放大**国产份额的机械抬升（分母缩小） |
| ⑧ 生物制品计税方式变更（外生） | 单家披露减少收入 6,410.82 万元、影响净利 5,449.20 万元 | 冲击 2026 年利润表，不改杠杆方向 |

头三项 ①②③ 解释「份额升而毛利不塌」差额 ≥80%。
**已从清单删除**：毒株的**份额效应**（单源区域流调、无量化路径）；渠道库存/牛鞭效应；网络密度。

## 4. 历史实证区间 ★（1 个完整区间，含数字）

**2023-08-22 至 2026-09-11，约 37 个月：**

| 时点 | 读数 |
|---|---|
| 2023-08-22（公告第 701 号）起 | 8 款产品 / 24 家次通过应急评价 |
| 2024-01-18 | 首个国产猫三联以**兽药临字** 020306072 上市，有效期至 2026-01-17（整 2 年） |
| 2024 全年 | 猫用疫苗批签发 **129 批次 / 12 家企业 / 8 个品种**；妙三多 34 批 = **26.36%**；国产 93 批 = **72.09%**；国产批次头部两家占 **41.94%** |
| 2025-07 / 09 / 11 | (2025)72 号（二类，监测期 4 年）、113 号、127 号陆续核发；9-29 公告披露「1 进口 + 1 国产持证上市，10 款国产临字上市」 |
| 2025 全年 | 批签发 165 批次；国产 139 = **84.24%（次数口径）**；妙三多 26 = **15.76%** |
| FY2025 | 外资在华收入 2.27 亿美元，同比 **−15.93%**（列报 −16%）；较 FY2022 的 3.82 亿 **−40.58%** |
| 2026 年内 | 临字密集到期：020306072 至 2026-01-17、140406077 至 2026-09-10 |

**回测定性：验证了一半，暴露了另一半的边界。**
- 验证：份额重排严格跟随临字放量节奏；外资份额与收入同步收缩。
- 暴露：同期持证方毛利率不降反升（+4.90 pct），说明份额竞争未转化为价格竞争；而企业口径出现「自杀式竞争」自述 + 2026 年到期潮，构成对「价格塌得慢」的**未决观察**。

## 5. 常见误读与纠错（❌ / ✅）

| ❌ 流行说法 | ✅ 正解 |
|---|---|
| 国产猫三联已有 19 家拿到批文 | 逐公告清点为 18 家次、企业口径 16 家次；且「批文」把注册证书、临时文号、正式文号三种证件压成了一个数。19 的误差来自把同一企业重复计入两张证书 |
| 批签发国产占比 84.53%，国产已拿下这个品类 | 84.53% 的量/次数口径未定；按次数重算是 84.24%（2025），2024 年是 72.09%。只有 2024 年存在两条独立路径可互验（129 批次） |
| 国产把进口价格打到六到七折 | 该比例在公开材料中不可复现：电商裸品价与门店含服务价不可比、外资品牌书面否认授权电商、猫三联无政采/挂网中标记录。**本 SOP 不给价格降幅数字** |
| 妙三多是进口产品，国产在替代进口 | 妙三多现持兽药生字、由苏州企业生产；其进口兽药注册证有效期止于 2022-06-21，美国产已于 2025-09 全部过期。真实对立是「持证资格种类」，不是国籍 |
| 批文放开 → 供给涌入 → 毛利被抹平 | 放开的是临字（≤2 年、资料要求降低），它给的是卖货权不是产能期限；资本开支因此不跟进（有募投项目终止的直接证据），毛利反而上升 |
| 宠物医疗增长靠养宠数量 + 消费升级 | 数量与客单价均为温和上行，同期可交付供给在三年里从 0 走到 139 批次。**当期变量在供给侧的持证资格** |
| 高毛利环节就是利润池 | 同一主体内毛利率与净利率可背离 47 个百分点（跨实体口径，仅量级示意）；终端连锁净利的 98.4% 来自政府补助与税收优惠；一家公司归母 +141.68% 而扣非 −67.42% |

## 6. 口径陷阱表（哪些数字不能互相比较）

| 不可比较对 | 原因 | 处理 |
|---|---|---|
| 批签发**量** vs 批签发**次数（批次）** | 单批规模差异大 | 分列，禁同式；本文只用次数口径 |
| **家次** vs 企业 vs **款** vs 文号 | 一款可由 5 家联合研制；家次 ≠ 企业 | 跨单位比值只作量级示意并显式声明 |
| 文号**有效期起止（时点）** vs 批签发**年度批次（期间）** | 时点 ÷ 期间无意义 | 标注「仅示意」，不推产能 |
| **注册证书** vs **临时批准文号** vs **正式批准文号** | 三种证件、两种通道、法定效力与寿命不同 | 拆开计数，禁止合并为「批文数」 |
| **临字/生字** vs **监测期** | 临字挂在应急评价；监测期挂在核发新兽药正式文号时 | 两把锁分开陈述，禁写「临字到期换生字」 |
| 母公司分产品口径 vs 子公司口径 | 基数不同（5.23 亿 vs 5.3 亿） | 落差仅作量级示意 |
| 同一公司含贸易转售的「宠物板块」 vs 另一公司的纯制造「宠物用疫苗」 | 分部定义不同 | 禁跨公司比毛利率 |
| 2026-01-01 前后收入 / 价格 | 生物制品改一般计税 + 分部口径变更 | 禁跨年同比 |
| 电商裸品价 vs 门店含服务价 | 服务与产品混计 | 分列，禁算价差 |
| 协会规模以上均值 vs 上市公司分部值 | 样本范围不同且偏差方向为偏大 | 禁相减得「超额利润率」 |

## 8. 失效条款 ★

**F1（强制）** 若「国家兽药基础数据库的企业批准文号查询」或「中监所批签发公示」停止更新 / 变更口径 → 本 SOP 自动降为 Draft，30 日内寻找替代源（路径：逐家企业的《关于获得兽药产品批准文号批件的公告》拼接）。
*现状注记：本期已无法逐条调取该数据库，F1 的前置条件已部分触发，故定级不得高于 Draft。*

**F2（强制）** 若连续 2 期「临字放量 → 份额跃升」被证伪（临字款数增加而国产批签发次数占比不升），或出现第 2 个「正式文号批量换发而毛利率未下降」的反向读数 → **主链条作废，回 Phase 3 重新考古**。

**F3（行业特性）** 若出现下列任一，本节暂停适用：
- 猫三联进入省级以上集采 / 带量采购目录 → 独有性论证失效，退化为一般兽药逻辑；
- 公告附件中宠物用疫苗类品种监测期标注为「/」（不设）→ 排他时钟消失；
- 宠物医疗保险渗透率达到可显著改变高价疫苗支付弹性的水平（**须先有公开可核的渗透率序列**，本期没有）。

**F4（本 SOP 特有）** 若「临字换发生字」在《兽药产品批准文号管理办法》修订中被正式条款化 → 本 SOP 的「两种资格并存」框架须改写为「两阶段递进」，第 1 节的传导链要重画。
