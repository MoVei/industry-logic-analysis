# 五级数据源地图

> 每个数字必须能追溯到具体发布方与具体报表。
> 「参考行业数据」「据行业估算」这类表述一律不合格。

---

## L0 国家级官方与交易所（首选）

| 来源 | 覆盖 | 常用报表/栏目 |
|---|---|---|
| 国家统计局 | 宏观经济、工业产量、人口、价格指数 | 月度数据、分行业数据库、季度 GDP 核算 |
| 中国人民银行 | 货币信贷、社会融资 | 金融机构信贷收支表、社融存量 |
| 海关总署 | 进出口量额 | 分商品月度进出口统计 |
| 财政部 | 财政收支、国债 | 财政收支情况月度快报 |
| 工信部 | 工业运行、产能 | 原材料工业运行情况 |
| 国家发改委 | 价格、产业政策 | 价格监测中心、成品油调价 |
| 农业农村部 | 农牧渔 | 生猪产品月度供需分析、农产品供需形势 |
| 上期所 / 大商所 / 郑商所 / 中金所 / 广期所 | 期货品种库存仓单 | 交割库库存周报 |
| 证监会 / 交易所 | 上市公司披露 | **年报、半年报、季报的分部数据**（核实产业链单环节利润率的最佳来源） |

**要求**：结论必须能落到**具体报表或月报名**，不许写「国家统计局数据」了事。

## L1 行业协会一手数据（高频首选）

| 来源 | 覆盖 |
|---|---|
| 中国汽车工业协会 / 乘联会 | 汽车产销、新能源渗透率 |
| 中国有色金属工业协会 / 安泰科 | 有色冶炼产量、加工费 |
| 中国钢铁工业协会 | 粗钢产量、钢材库存 |
| 中国煤炭运销协会 | 煤炭产运销 |
| 中国光伏行业协会 | 各环节产量、价格 |
| 中国物流与采购联合会 | PMI 分项 |
| 中国畜牧业协会 | 生猪、禽类存栏出栏 |

**注意**：使用协会数据**必须标注样本口径与偏差方向**（协会通常只覆盖规模以上企业）。

## L2 专业数据商（可用，须标注）

Mysteel/钢联、卓创资讯、隆众资讯、百川盈孚、涌益咨询、SMM 有色网、安泰科、Clarksons、Platts、Argus、Fastmarkets、Wood Mackenzie、AZ China。

**标注要求**：机构名 + 样本口径 + 数据频率。不许隐去机构名直接当作事实引用。

## L4 / L5 券商研报与媒体报道

**限定三种用途，违反即不合格**：

1. **找线索** —— 由此反向去 L0—L3 核原始出处
2. **引用专家实名原话** —— 必须署名并注明场合与时间
3. **交叉印证** —— 已有 L0—L2 结论时，用它作为第二个独立来源

**明令禁止**：
- ❌ 作为唯一来源
- ❌ 把预测值写成事实（预测值必须标注「某某机构的预测值」）
- ❌ 转述时不标原始发布方

---

## 标注规则（强制）

每个数字必须带三件套：**来源 + 期间 + 口径**

| 要素 | 示例 |
|---|---|
| 来源 | 国家统计局 / Mysteel / EIA / 某公司 2026 半年报 |
| 期间 | 2026Q3 末 / 2026 年 1—9 月 / 2026-10-15 当周 |
| 口径 | 季末时点数 / 期间累计数 / 规上企业样本 / 全口径 |

完整示范：
```
能繁母猪 3,602 万头（国家统计局，2026Q3 末，季末时点数，同比 −10.7%）
```

---

## 明令禁止清单

```
❌ 「据媒体报道」「据悉」「市场普遍认为」等无源表述
❌ 把二手转述写成一手来源（正确写法：128 万吨（海关总署，经机构综述转引））
❌ 用估算值填补数据缺口 → 缺口走数据缺口表
❌ 口径不同的数字放在同一句对比（时点 vs 期间、家庭 vs 全口径、头部 vs 全国平均）
❌ 引用未标注发布方的高频数据
❌ 数据超过 45 天（月度）/ 105 天（季度）未更新仍直接使用
```

---

## 找不到数据时的处理

1. 至少尝试 **2 个不同级别**的来源（如 L0 无果再查 L1、L3）
2. 仍无果 → 登记进《数据缺口表》，写明：缺口项 / 缺失原因 / 尝试过的来源 / 对结论的影响
3. 缺口必须在正文里原样出现

**不估算填空。**
