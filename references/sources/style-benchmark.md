# 风格范本要点摘录

> 范本：《买在需求点：糖的投资逻辑》（用户提供，已通读）
> 用途：**写作风格对标**。它定义了这套产出的表达基调。
>
> ⚠️ 本书**只作为写作风格的范本**，不是选题范围。
> ⚠️ 本文件摘录的是**结构与笔法**，不含具体数据。任何具体数据都必须回到 `data-source-map.md` 现场取证。

## 一、这本书确立的三件事

### 1. 从需求端切入，而不是从供给端开始

传统行业分析习惯从「谁在生产、产能多少」讲起。范本反过来：**先回答谁在买、为什么买、能不能不买**。

对这个 Skill 的意义：Phase 1 需求端解剖被设为不可跳过的阶段，正是这条原则的制度化。

### 2. 用产业链的实际运行逻辑解释现象，而不是用概念解释现象

「供需关系决定价格」是概念。「把这批糖从产地运到销区需要经过哪些环节、每环节的边际库存是多少」是运行逻辑。

概念无法证伪，运行逻辑可以。**每写一个机制，都要能指出它发生在链条的哪一环、由谁执行、多久见效。**

### 3. 场景和数据替代理念

读者记住的是场景：某个具体时点、某个具体价格、某个具体决策。

## 二、可迁移的笔法清单

| 笔法 | 做法 |
|---|---|
| **具体场景开场** | 落到真实价格、真实动作、真实地点 |
| **消费侧的重要性住房** | 先讲买方视角，再讲生产方，让读者先关心再理解 |
| **产业链逐级下钻** | 每个环节都问「它凭什么存在、它赚什么钱」 |
| **数据与南定结合** | 每个数字后面跟着一个具体的市场行为，而不是跟着一个形容词 |
| **不回避周期性** | 讲清周期由什么驱动、为什么反复出现、当下的位置在哪 |

## 三、本 Skill 相对范本的差异（重要）

范本是**一本书，讲一个品种**。本 Skill 产出的是**跨行业的引擎**。因此做了三处调整：

| 维度 | 范本 | 本 Skill |
|---|---|---|
| 覆盖 | 单一品种 | 七类行业通用路由 + 行业专属 SOP |
| 机制分析 | 融入叙事 | 独立为 Phase 3，要求量化 + 历史回测 |
| 沉淀 | 一次性成书 | 每期沉淀可复用 SOP，带定级与失效条款 |

**保留的**：需求端优先、链条下钻、场景化表达、数据驱动。
**加强的**：幂等防重复（台账）、可证伪性（反证清单）、权威性维护（三级定级 + 验证履历）。
