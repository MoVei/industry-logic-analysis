# 链条绘制与利润归属方法

> Phase 2 的方法依据。
> 目标：回答「利润最终留在哪一环，以及它凭什么留得住」。

---

## 一、链条粒度标准

**相邻两环节之间存在一次真实的市场交易**，才拆成两环。

粒度过粗的表现：把「生产→销售」当两环，中间所有机制都看不见。
粒度过细的表现：企业内部工序被拆成环节，产生虚假的市场交易。

### 典型链条示例

| 行业 | 链条切分 |
|---|---|
| 生猪 | 祖代 → 父母代 → 仔猪 → 育肥 → 屠宰 → 批发零售 |
| 光伏 | 工业硅 → 多晶硅 → 硅片 → 电池片 → 组件 → 电站 |
| 现制茶饮 | 原料 → 品牌方 → 加盟商 → 外卖平台 → 消费者 |

## 二、每环节四项画像

| 字段 | 取值 | 说明 |
|---|---|---|
| **集中度** | CR3 / CR5 | 取不到写「分散」并注明数据源缺失 |
| **议价权来源** | 技术壁垒 / 资源垄断 / 牌照 / 规模 / 渠道 / 切换成本 | **必须选一项并举证**，不许写「综合优势」 |
| **进出价格** | 买入价 → 卖出价 | 形成该环节的价差或加工费 |
| **代表性主体** | 上市公司或龙头 | 便于后续用公开数据核对 |

## 三、成本曲线画法

行业的边际成本分位决定价格底部在哪。

### 步骤

1. 取各主要生产主体的**单位完全成本**（优先用上市公司分部数据或行业统计）
2. 按成本从低到高排序，横轴累加产能
3. 画出累计产能—成本曲线
4. 标出**当前市场价格落在哪个分位**
5. 判断：该价格下有多少产能处于现金亏损 → 这部分产能是退出的候选

### 三类关键价格

| 价格 | 含义 |
|---|---|
| **现金成本** | 低于此线企业立刻停产 |
| **完全成本** | 低于此线企业会计亏损但短期仍会生产 |
| **边际成本曲线与需求的交点** | 中长期均衡位置 |

> 参考案例（仅作方法示范，不得转录数据）：铝那期以电价为核心变量画出成本曲线，用「锅盖（产能）与座位（需求）」类比讲清为什么价格跌到某分位就有产能退出。

## 四、利润池判定 ★

### 核心纠偏

**账面营收高 ≠ 留存利润高。**

营收规模大的环节往往是「过路财神」：流水大，但上下游都在挤它的价差。

### 判定方法

```
某环节回报率 = 该环节价差（或加工费） ÷ 该环节必要资本开支
```

逐环节算出回报率，横向对比，利润池自然浮现。

### 交叉验证

用上市公司**分业务分部利润表**核对该环节利润率。分部数据比行业口径更可靠，但样本偏向头部，需注明偏差方向。

### 三种必检的错位形态

| 错位形态 | 表现 | 常见于 |
|---|---|---|
| **营收大的环节被两头挤压** | 流水大但利润率薄 | 中游加工 |
| **账面亏损但现金流为正** | 折旧摊销大，实际仍在贡献现金 | 重资产环节 |
| **利润留在上游而定价权在下游** | 上游赚资源租金，下游定终端价 | 资源型行业 |

## 五、进出口是否构成泄压阀

存在国际贸易通道时，判定它的实际作用：

| 判定 | 条件 | 对结论的影响 |
|---|---|---|
| **是泄压阀** | 国内外价差打开后会快速放量 | 压制国内价格上行空间，价格难超海外 + 运费 + 关税 |
| **不是泄压阀** | 存在配额 / 高关税 / 运输瓶颈 / 品质错配 / 长协锁定 | 国内价格可与海外阶段性脱钩 |

**必须写出限制具体是什么**，不许笼统说「受进口影响」。

## 六、常见错误清单

| 错误 | 正解 |
|---|---|
| 用营收规模判断谁赚得多 | 用价差 ÷ 资本开支判断 |
| 只看国内链条 | 有进口就必查国际价格与通道限制 |
| 集中度数据缺失就跳过 | 注明缺失，用上市公司数据做单点替代并标偏差 |
| 把企业内工序当市场环节 | 只在有真实交易处切分 |
| 画完链条不校验主链条假设 | 必须回答「真实主链条与假设的差异在哪」 |
