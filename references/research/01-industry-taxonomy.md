# 七类行业路由表

> 本表的作用是**给搜索起点，不给结论**。
> 每类的「主链条假设」必须在 Phase 2 用当期实证检验。**照抄假设视为重大缺陷。**

---

## A 资源 / 大宗商品

**举例**：原油、动力煤、天然气、铜、铝、锂、大豆、玉米、生猪

**关键变量**：产能投放周期、开工率、库存（显性 vs 隐性）、进口依赖度、政策保有量/储备

**主链条假设（待实证）**：
```
产能决策 → 建设/生长时滞 → 供给释放 → 库存缓冲 → 价格 → 反身性影响下一轮产能决策
```

**必查项**：产能投放节奏表、进口能否充当泄压阀、库存是蓄水池还是加速器

---

## B 中游材料加工

**举例**：PTA、乙二醇、PVC、钢铁加工、水泥、造纸

**关键变量**：加工费/价差（而非绝对价格）、产能利用率、原料成本占比

**主链条假设（待实证）**：
```
原料价格 − 产品价格 = 加工利润 → 决定开工率 → 供给弹性 → 反过来修正加工费
```

**必查项**：加工费历史分位、单线产能与边际装置位置、下游能否接受涨价

**性格提示**：这类行业看似在看原料，实质在看**加工利润的分配权**。谁在链条上被迫让利就是本期的关键。

---

## C 消费品 / 零售

**举例**：现制茶饮、家电、服装、白酒、餐饮连锁

**关键变量**：需求分层、渠道库存、单店模型、复购率、价格带迁移

**主链条假设（待实证）**：
```
客流 × 客单价 × 复购 → 同店销售 → 渠道库存 → 补货节奏（牛鞭效应源头）
```

**必查项**：单店 UE（投资回收期）、加盟 vs 直营结构、渠道库存天数、价格带是否在迁移

**性格提示**：消费品最常见的误判是把「渠道补货」当成「终端需求」。渠道库存天数是拆穿它的关键数据。

---

## D 装备 / 整机制造

**举例**：工程机械、锂电设备、光伏设备、船舶、轨交

**关键变量**：在手订单、产能爬坡曲线、折旧杠杆、交付节奏与收入确认方式

**主链条假设（待实证）**：
```
新增订单 → 排产计划 → 交付 → 收入确认（订单是最强领先指标）
```

**必查项**：在手订单覆盖率、新签订单同比、产能利用率、二手设备存量（会压制新机需求）

**性格提示**：产能一旦投放就是刚性，折旧杠杆会让开工率的微小变化放大成利润的大幅波动。

---

## E 平台 / 服务

**举例**：本地生活、OTA、SaaS、物流快递、招聘平台

**关键变量**：双边网络密度、单位经济模型（UE）、获客成本（CAC）与回收周期、留存

**主链条假设（待实证）**：
```
供给密度 → 匹配效率（等待时长/成交率） → UE 改善 → 扩张节奏
```

**必查项**：货币化率、补贴强度与 UE 的背离、单量 vs 客单价的结构、留存 cohorts

**性格提示**：平台行业的「规模」只有在密度够的地方才转化为效率。**总量增长掩盖密度不足**是最典型的陷阱。

---

## F 金融 / 地产

**举例**：银行、保险、券商、房地产开发、REITs

**关键变量**：利差、久期错配、杠杆率、信用成本、资产周转

**主链条假设（待实证）**：
```
政策利率 → 资产端收益率 vs 负债端成本 → 净息差 → 信用投放意愿 → 资产质量反作用
```

**必查项**：净息差趋势、不良生成率（非余额不良率）、拨备覆盖率、久期缺口

**性格提示**：余额类指标会被分母稀释。 **生成率类指标**才是当期风险的真实读数。

---

## G 科技 / 半导体 / 软件

**举例**：晶圆代工、存储、面板、SaaS、EDA

**关键变量**：良率爬坡、学习曲线、牛鞭效应、递延收入、产能预订率

**主链条假设（待实证）**：
```
需求预期 → 下单（超额下单） → 产能预订 → 渠道库存累积 → 砍单 → 断崖式下跌
```

**必查项**：稼动率、渠道库存周转天数、递延收入余额、ASP 趋势、资本开支指引

**性格提示**：半导体的周期放大来自**重复下单**。同一颗芯片被上下游同时下单，需求看似翻倍，砍单时同样翻倍。

---

## 跨类别通用复核（每期必答）

1. 本行业**实际**的主链条与上表的假设一致吗？不一致的话，真实的那条是什么？
2. 有没有**第二重要**的机制被假设漏掉了？
3. 我有没有找出一个**与流行说法相反的事实**？

三问答不全不许进 Phase 3。
