# 需求端与产业链运行逻辑分析

一套自研的投研方法论 Skill：**拆一个行业的运行逻辑，产出一根「别的行业没有、但在这个行业里决定一切」的因果杠杆**，并沉淀带失效条款的行业 SOP。分析纪律是硬性的——每个数字带来源＋期间＋口径，每条结论的出处可逐条回查（正文写「机构＋期间」，编号留在文末对照表），成稿与审校由不同角色承担，审校必须挑出真问题。

- 双轨：**industry 轨**（行业／品种，默认）· **company 轨**（单家上市公司，11 节报告）
- 组织单位：**行业文章集**——一个行业一个系列，集内多篇按 `NN-<阶段>-<标题>` 顺序编号（开篇 → 展开 → 深挖 → 反例 → 边界），由 `_系列索引.md` 记录已覆盖的子方向与视角，防止同题重写
- 读者：**外行**——没读过这个行业任何报告、但有生活常识和初中算术的人。正文零底稿编号、零内容标签，段与句的颗粒度有可机械检查的门槛（`readability-check.py`）
- 第〇节硬边界（不可关闭）：**不输出目标价、不预测涨跌、不给买卖时点与仓位、不做个股推荐与情绪/资金/技术面分析**；估值只做「当前价格隐含了什么预期」的反推
- 方法论、七阶段流程、门禁与目录约定：见 [方法论与目录结构](方法论与目录结构.md)
