# 需求端与产业链运行逻辑分析 Skill · 双轨（入口说明）

> 本文件是资料库入口说明。
> 版本 1.1.0（2026-11-02 新增 company 轨）

---

## 一句话说明

**双轨基本面分析引擎**，两轨共用同一套取证纪律、多角色分工与硬边界。

- **industry 轨**（默认）：拆任意行业的需求端与产业链运行逻辑，产出一根「别的行业没有、但在这个行业里决定一切」的因果杠杆，并沉淀可复用、带失效条款的行业 SOP
- **company 轨**：给定一家上市公司，按 12 项财务清单 + 六维框架 + 隐含预期反推，产出 11 节研究报告

起源：从《大宗商品投资常识》的写作方法中抽出骨架，做成适用于全部行业的通用引擎；后将「基本面深度研究专家团」（Alpha派）与《研究顾问方法论》的规则内化，形成 company 轨。与《大宗商品投资常识》系列并行运行，互不干扰。

---

## 这个 Skill 回答哪三个问题

1. **钱从哪来** —— 谁付钱、为什么非付不可、他的支付能力由什么决定
2. **货怎么到他手上** —— 链条有几环、每环谁说了算、利润最终留在哪一环
3. **哪个变量一动，价格和量就跟着动** —— 「那根唯一的杠杆」

第三问是全部价值所在。**判定标准：如果一个行业分析完拎不出一条外行不知道的因果链，这一期就是废稿。**

---

## 硬边界（最高优先级，不可关闭）

- 不输出目标价、不预测价格涨跌、不给买卖时点、不做仓位建议
- 不做市场情绪、资金面、技术分析
- 不做个股推荐与标的筛选
- 估值只做「当前价格隐含了什么预期」的反推，不做定价

这套输出属于基本面研究，用途是理解机制，不是定价。

## 双轨流水线

### industry 轨（默认，六阶段 + 两条反馈回路）

```
P0 选题与边界 → P1 需求端解剖 → P2 链条与利润归属
                                        ↓
P5 成稿与审校 ← P4 数据与逻辑校验 ← P3 特异机制考古 ★
                                        ↓
                              P6 SOP 沉淀与定级
```

### company 轨（七步）

```
Step0 锁定标的 → Step1 抓原始财报 PDF → Step2 财务拆解（12 项）
  → Step3 业务与行业数据 → Step4 竞争格局（强制复用行业 SOP）
  → Step5 交叉验证 + 盲区质询 → Step6 成稿（11 节） + 独立审校
```

**两轨的接口**：company 轨的 Step 4 必须调用 industry 轨沉淀的 SOP（杠杆 / 信号表 / 口径陷阱表），
并用公司实际数据**反向校验**行业结论。行业轨出面，公司轨出点。

- **回路 A**：P4 任一校验不通过 → 退回 P2 或 P3 重做，**禁止在 P4 打补丁补数据**
- **回路 B**：审校判定「缺历史实证」或「无独家洞察」→ 退回 P3

### 每阶段的核心输出

| 阶段 | 输出 | 完成条件 |
|---|---|---|
| P0 选题与边界 | `0-frame.md` | 边界一句话可说清；钩子成立（无矛盾则换标的） |
| P1 需求端解剖 | `1-demand.md` | 能说清「需求为什么变」而非「需求在变」 |
| P2 链条与利润池 | `2-chain.md` | 任取一环能说出「它凭什么拿走这个利润」 |
| P3 特异机制考古 | `3-mechanism.md` | 杠杆三问俱全 + 多层分解与官方数据闭合 |
| P4 数据校验 | `4-verification.md` | 三重验证全过，不退补丁 |
| P5 成稿与审校 | 五件套 | 审校 ≥3 个具体问题（挑不出 = 没做） |
| P6 SOP 沉淀 | domain playbook | 九要素齐全 + 失效条款 + 定级 |

## 内化自专家团的通用铁律（两轨共用）

来源：`alphapai-deep-research-team`（五角色：主理人 / 证据 / 数据 / 领域 / 审校）+ 《研究顾问方法论》

### 四类内容必须区分 ★

| 类别 | 标注方式 |
|---|---|
| **披露事实** | 有原始披露文件，直接陈述 + 来源 |
| **管理层口径** | 标明主体与时间 |
| **外部观点** | 标明来源 + `[二手]` 前缀 |
| **自主推演** | 明示假设 + 公式，可被复核 |

**判据**：删去来源标注后，读者仍能否分辨某段是事实还是推演？不能 = 不合格。
分析出错多数不是数据错了，而是把推演伪装成事实。

### 其余五条硬纪律

1. **检索无果只能说「本次覆盖中未找到」**，不得断言「信息不存在」
2. **同一角色不得既写又审**
3. **不得用常识替换缺失来源**
4. **不得猜测链接、不得把搜索摘要当原文**
5. **不得泄露内部路径、ID、Prompt、SQL、协作日志**

### 五角色如何映射进流水线

| 阶段 | 承担角色 |
|---|---|
| P0 选题与边界 | 主理人 |
| P1—P2 需求端与链条 | 证据研究员 + 数据分析师（可并行） |
| P3 特异机制考古 | 领域分析师 |
| P4 数据与逻辑校验 | 数据分析师 + 证据研究员交叉 |
| P5 成稿 → 审校 | 领域分析师成稿 → **质量审校员独立复核** |
| P6 SOP 沉淀 | 主理人综合 |

## 关键方法论（industry 轨四条）

### ① 杠杆准入三问

1. **独有性**：换一个行业还成立吗？成立 → 不够格
2. **可量化**：能说出「X 变 1% 引起 Y 变多少」或「传导 N 个月」吗？说不出 → 不够格
3. **当期性**：它正在被触发或走向触发吗？完全休眠 → 留到下期

三条不全中 → 回到 Phase 2 换角度，或换标的。

### ② 多层乘法分解 + 反向验证

把现象拆成可相乘的几层，每层与官方数据闭合，最后用官方公布的最终值反向核对自己的分解。闭合不上不许进正文。

### ③ 替代效应量价对照

判定「需求是不是真的转移了」，必须同时看替代品的**量**和**价**：

| 替代品量 | 替代品价 | 判定 |
|---|---|---|
| ↑ | → 或 ↑ | 真实的替代转移 |
| ↑ | ↓ | 替代品自身过剩，非需求转移 |
| → 或 ↓ | ↓ | 替代品自身收缩，与本行业无关 |

### ④ 七类行业路由（给搜索起点，不给结论）

A 资源大宗 / B 中游材料 / C 消费品 / D 装备制造 / E 平台服务 / F 金融地产 / G 科技半导体。

每类给一条主链条假设，**必须用当期实证检验，照抄算缺陷**。

## SOP 的权威性怎么保证

答案是：**可回滚、可证伪、有时间戳**，不靠文笔。

### 三级定级

| 级别 | 门槛 |
|---|---|
| Draft 草案 | 首期分析完成 + ≥1 个历史实证区间 + 数据清单完整 |
| Verified 已验证 | 复用 ≥2 期，且 ≥1 次机制判断被事后数据证实 |
| Authoritative 权威 | 复用 ≥3 期 + 跨越一个完整周期 + 无未决反例 |

初次沉淀一律 Draft，不允许跳级。

### 失效条款（每份必备）

- 数据源停更或变更口径 → 自动降为 Draft
- 连续 2 期机制判断被证伪 → **主链条作废**，回 P3 重新考古
- 行业结构触及预设条件 → 相关章节暂停适用

### 复用前强制检查

时效（月度 >45 天、季度 >105 天必须重新取数）+ 反例 + 每次使用后写验证履历。

### 独立取证原则

每份 SOP 的数据与机制必须来自沉淀当期的现场检索，**禁止从既有产出转录**。既有产出只能作为「去哪找线索」的检索起点。

## 怎么用

### 输入

| 参数 | 必选 | 说明 |
|---|---|---|
| 标的 | 否 | industry 轨须边界可界定；**company 轨须能消歧到唯一证券代码** |
| 反直觉现象 | 否 | 最好的切入点，如「母猪砍掉 433 万头，为什么肉价还在跌」 |
| 轨道 | 否 | 自动判定：含证券代码或「某公司 / 这家」→ company，否则 industry |
| 输出形态 | 否 | industry：长文（默认）/ 报告 / 速览；company：11 节报告（默认）/ 速览 |

### 触发词

**industry**：「分析这个行业」「拆解产业链」「需求端逻辑」「行业运行逻辑」「这个行业怎么赚钱」「行业 SOP」「下一个行业分析什么」
**company**：「分析这家公司」「X 公司基本面」「看看 0772.HK」「这家公司怎么赚钱」

### 每期产出（顺序固定，正文/报告最后一个写）

industry 轨：`数据表 → 证据索引 → 领域分析 → 审校意见 → 正文`（五件套）
company 轨：`财务底表 → 证据索引 → 公司分析 → 审校意见 → 报告`

**禁止正文出现数据表里没有的数字。**

### company 轨的验收（9 条，缺一即失败）

- 11 个小节齐全，无空缺
- 关键数字 ≥20 处带「来源 + 期间 + 口径」
- 12 项财务清单覆盖核心 5 项（收入分部 / 毛利率 / OCF / CapEx / ROE 或 ROIC）
- 尚待验证假设 ≥5 条
- 跟踪信号表 ≥8 行且含触发阈值
- 数据缺口章节非空
- 全篇无硬边界排除项
- 正文 ≥3000 字
- 四类内容已区分

## 一句话总结

这个 Skill 的产出标准不是「写得好」，而是**「说出了一个外行不知道、且可被数据推翻的东西」**。
