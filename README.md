# industry-logic-analysis

拆解任意行业的需求端与产业链运行逻辑，产出一根「别的行业没有、但在这个行业里决定一切」的因果杠杆，并沉淀可复用、带失效条款的行业 SOP。

- 主文档：[SKILL.md](SKILL.md)（七阶段流水线 + 五件套产出 + 硬边界约束）
- 执行阶段：`phases/`（P0 选题定边界 → P6 SOP 沉淀定级）
- 参考资料：`references/`（行业路由表、需求模型、机制模式库、数据源地图、防重复台账、行业 SOP）
- 模板与配置：`assets/`；辅助脚本：`scripts/`；用例：`tests/`
- 已产出分析：`产出/`（宠物医疗、生猪养殖等）

## 硬边界（不可覆盖）

不输出目标价、不预测价格涨跌、不给买卖时点、不做仓位建议、不做个股推荐；估值只做「当前价格隐含了什么预期」的反推。每个数字必须带「来源 + 期间 + 口径」三件套，数据缺口直说、不估算填空。
