## 二、那根杠杆的证据链

**本期杠杆**：中国碳酸锂的供给**不由价格决定，而由「证照周期 + 渠道持货意愿」两台时钟决定**。矿端与冶炼端在价格暴跌时都不退出（证照与物流决定开工，转换器属性决定冶炼不因亏损而出清），唯一真正响应价格的是**贸易商的持货意愿**；而广期所的仓单时钟（60/240 天有效期 + 3/7/11 月强制注销 + 单一注册品牌免检）把「现货在谁手里」与「期货能交割多少」切成两个数量级，于是价格的下行压力被完整地分配到**渠道去杠杆**这一格。

## 三、杠杆准入四问

| 问 | 回答 | 判定 |
|---|---|---|
| ① 独有性 | 换到铜、铝、生猪，供给开关在既有 SOP 里主要是**成本曲线**或**生物时滞**；本期在锂上取到的是第三种：**三起停产逐条为证照、物流、设备，无一为价格**（D360／D362／D363），叠加一套按 60／240 天切碎的可交割货源（D400、D404）。限定：证照闸门以枧下窝为**可完整回溯的显著个案**，且存在反例（永兴化山矿换证未减采，D364），故不写成普适律；本问成立所依赖的是「退出不由价格触发」这一较弱的、可核的说法。同一元素在链条上有三种持证形态（矿权证／生产许可／注册品牌仓单），使退出机制不走成本曲线出清 | ✓（附限定） |
| ② 可量化 | 贸易商占去库 91.84%／98.85%；上游 −133 吨 = 总变动的 0.32%；证照周期 14.7 个月；仓单有效期 60／240 天、每年 3 个强制注销点；矿端让利 −2.46%（月）／−11.2%（周）；地板价 1,000 美元/吨；名义利用率 54.83%；藏格单吨价 +81.9% 对成本 −11.0% | ✓ |
| ③ 当期性 | 2026-10-30 枧下窝环评获批；2026-11 旧标准仓单强制注销窗口；库存 8 周内从 169,347 降至 128,385 吨并触及该口径区间低点；10-29 期货创年内新低；11-02 盘中反弹至 93,680 元/吨 | ✓ |
| ④ 必要性（反事实） | 见下节 | ✓ |

**第 4 问的逐层剥离**：
- **只有价格—成本机制（传统大宗模型），没有证照闸门**：矿证到期不构成停产理由，枧下窝的 14.7 个月行政链条（审计署→矿产资源法→矿种变更→矿证→安许→环评）无从解释；而它恰是 2026-10 那轮一周 −20% 下跌的直接触发（10-22 拟批准公示 → 10-30 批复）。
- **只有证照闸门，没有「转换器」属性**：外购辉石亏 6,544—15,012 元/吨时冶炼应减产，供给随之收缩、价格回到成本线；实际开工率 +0.4pct、产量环比 +2.5%、原料库存 +4.6 万吨，且中国境内零永久退出——盛新「以加工费确认收入」的净额法会计把这件事写在了报表口径上。
- **只有矿与冶炼，没有渠道持货意愿**：库存变动无法解释——总库存 −40,962 吨的同时上游只动 −133 吨，说明全部压力由贸易商承担；若价格信号落在生产端，去库应表现为冶炼库存下降与产量收缩。
- **没有仓单时钟**：就会出现「库存去化 → 现货宽松 → 基差走弱」的单一方向；实际是基差自 8 月贴水 −2,860 转为 10-08 的 +5,700 升水，且仓单同期降至 17,121 吨——升水与仓单收缩都由 60/240 天与 3/7/11 注销点制造。
- **若需求端是当期变量**：装车 +16.7% 应主导锂价方向；实际产量 +63.4%、储能销量 +111.8%，锂的当期变化发生在持货结构而非终端数量。
→ **缺任何一层，「价格年内 −56.8%、全行业利润同比 +121%、冶炼在亏损中增产、去库 92%—99% 来自贸易商」这四件事同时成立就无法解释。**
