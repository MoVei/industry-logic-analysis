# 0-frame: 碳酸锂（含氢氧化锂对照）

> 生成日期：2026-11-02　期号：第 03 期　形态：longform
> 本文件是 `phases/00` 步骤 0.2 五维打分、0.4A 钩子类型硬筛、0.4B 答得圆满预检的留痕。

## 一、标的卡

- 所属大类：**A 资源 / 大宗商品**（分类表「举例」中显式列入「锂」）
- **主链条假设（抄自分类表，Phase 2 必须实证检验，照抄算缺陷）**：
  ```
  产能决策 → 建设/生长时滞 → 供给释放 → 库存缓冲 → 价格 → 反身性影响下一轮产能决策
  ```
- 关键变量：产能投放周期、开工率、库存（显性 vs 隐性）、进口依赖度、政策保有量/储备
- 必查项：产能投放节奏表、进口能否充当泄压阀、**库存是蓄水池还是加速器**
- 模式库预警（第 3 类「成本曲线分位」、第 7 类「库存缓冲/加速器」）：本期必须回答假设里的「库存缓冲」到底是哪一种，并否证或证实它。

## 二、边界

- **覆盖**：碳酸锂（电池级、工业级）为主线；氢氧化锂仅作替代品对照与贸易方向翻转用；上游锂辉石/锂云母/盐湖的原料端价格与成本；中游冶炼加工费与开工；渠道库存与广期所仓单制度；终端正极与电池的量价。
- **不覆盖**：矿权交易与勘探、电池制造成本结构、储能项目经济性、六氟磷酸锂/电解液/隔膜等其他锂电材料、钠离子电池产业化进度（仅作替代缺口处理）。
- **时间范围**：价格与库存取至 2026-11-02 可核到的最新读数；成本与产能取 2025 年报、2026 三季报与协会 2025 年度值。
- **地理范围**：以中国为枢纽（中国冶炼产能与渠道库存为主战场），矿端覆盖澳/非/南美，需求端覆盖全球。

### 采用的钩子（C 类）

- **一句话**：市场每天引用的「碳酸锂在去库」是真的——总量从 169,347 吨降到 128,385 吨；但把四个环节分开算，**总去库 −40,962 吨里 −37,618 吨（91.8%）来自贸易商，上游冶炼只减 −133 吨、电芯厂还 +545 吨**。换机构、换一套环节定义（Mysteel 207 家）：−30,540 吨里 −30,190 吨（**98.9%**）来自贸易商，锂盐厂 **+3,200 吨**。被算错的不是总量，是**「谁在持有库存」被当成了「供给紧不紧」**。
- **流传值 / 重算值 / 倍数差**：流传「持续去库 = 供给收紧」；重算后上游变动仅占总变动的 **0.3%**（−133 ÷ −40,962），即把「供给端在收」这件事高估约 **300 倍**；第三家机构（百川，只统计冶炼端工厂库存）同期从 25,183 吨升至 30,195 吨，**+20%，方向相反**。
- **层级自检**：性质问题（同一个「去库」在两种持货结构下方向相反，且决定它是蓄水池还是加速器），不是量的分解。✓

## 五、答得圆满预检

**把钩子翻译成算式，逐项标来源层级：**

| 算式项 | 表达式 | 来源层级与独立性 |
|---|---|---|
| 分项与总量闭合 | 32,115 + 39,609 + 41,950 + 20,698 = 134,372 | L2 SMM 货权口径；对 6 个周度读数逐行复算，全部偏离 0 |
| 环比变动闭合 | −3,343 − 3,275 + 773 + 700 = −5,145 | 同上 |
| 贸易商占比 | −37,618 ÷ −40,962 = 91.8%；−30,190 ÷ −30,540 = 98.9% | **两条独立路径**：SMM 货权口径 vs Mysteel 207 家样本（机构、样本框、环节定义均不同） |
| 上游方向 | SMM −133 吨；Mysteel **+3,200 吨**；百川 **+5,012 吨** | 三家同向或近零，无一支持「上游去库」；华泰期货 2026-10-22 原文直接写「主要是贸易商和下游去库，**上游锂盐厂库存增加**」 |
| 机制落点 | 自算开工率 97.6 ÷ 178 = 54.83%，对 SMM 周度 51.63%—52.01% | L1 协会口径 × L2 SMM，两主体独立，量级闭合 |
| 冶炼利润（例证层） | 外购锂辉石 −15,012 元/吨；外购锂云母 +937 元/吨；盐湖现金成本 33,900 元/吨 vs 电碳 98,300 元/吨 | **全部 L2 测算 → 按律二降级为例证**，不承载核心结论；另有多家给 −4,579、−19,000—20,000 等互斥值，走口径分层 |
| 需求端 | 磷酸铁锂 387.5 万吨 +56.2%、三元 81.3 万吨、氢氧化锂产量 35.6 万吨 **−13.9%**、2026H1 氢氧化锂出口 2.27 万吨 / 进口 3.17 万吨（**转为净进口**） | L1 协会 + 海关（经协会/期货公司转引，须标注） |
| 制度端 | 仓单有效期基准品 60 天、替代品 240 天；每年 3/7/11 月最后一个交易日前全部注销；〔2025〕410 号旧标准仓单 11 月底强制注销且不可重新注册 | **L0 规则原文**（业务细则，2024-12-06 修订）；410 号文号仅见中粮期货转引 → **单源**，正文按「据期货公司转引的广期所发〔2025〕410 号」表述 |

**预判结论：能闭合。** 核心结论由两条独立路径 + 一条同向佐证支撑，每条在自身口径内与总量精确闭合（偏离 0）。机制层两处只能到 L2 测算的部分，已预先安排降级，改由 L1 协会产能/产量口径的自算开工率承载定量结论。**不带着残差进 Phase 3。**
