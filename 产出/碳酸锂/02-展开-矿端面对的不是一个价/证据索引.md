## 二、那根杠杆的证据链

**本期杠杆**：锂资源端的成本曲线**不是按矿山成本高低排列的，而是按「你收到的是哪一口径的钱」排列的**——同一时点存在三个价差（现货指数 1,200—1,340 美元、折 SC6 的到港实现价 2,048 美元、矿山季报实现价 1,966—2,130（均为 3Q26） 美元），也存在三个成本口径（site 现金、FOB、CIF/AISC），三者之差达 32%—44% 与 1.37 倍。因此「跌穿成本线」这句话必须同时说明用的是哪个价、哪个成本；说明之后会发现，**真正跌破的是中国无自有矿的冶炼端，矿端覆盖倍数最低的也还有 2.0 倍，而它在扩产**。矿端的响应函数是「滞后 + 跨周期假设 + 证照与环保」，不是「价格 → 减产」。

## 三、杠杆准入四问

| 问 | 回答 | 判定 |
|---|---|---|
| ① 独有性 | 铜、铝的供给弹性写在**冶炼加工费与电力成本**里；生猪写在**生物时滞**里。本期在锂上取到的是：**同一种商品在矿端存在三个不同的价格（指数／到港价／实现价）与三个不同的成本（site／FOB／CIF＋AISC），且缓冲系数是合同条款的函数（0.48 对 0.99）**。这种「价格不是一个数」的结构在既有三套 SOP 中未见同构 | ✓ |
| ② 可量化 | 缓冲系数 0.48／0.99；实现价 1,966—2,130（均为 3Q26） 对 指数 1,200—1,340（低估 32%—44%）；覆盖倍数 1.0—7.3；海关折 SC6 2,048 对 财报 2,077／2,130（偏离 1.4%—3.85%）；扩产落地 2028—2030；Bald Hill 滞后 7 个月；云母 −16%／−13.8% | ✓ |
| ③ 当期性 | 2026-10-28／10-29 PLS 与 IGO 季报、11-02 Sigma 预告、2026-09-29 Liontown FID、2026-10 月 P2000 最终投资决定、2026-10-30 枧下窝批复、2026-10-12 茜坑安设审查、2026-10-09 津巴布韦再拒延期 | ✓ |
| ④ 必要性（反事实） | 见下 | ✓ |

**逐层剥离**：
- **若矿端只面对一个价格（现货指数）**：则 −57% 的回撤应即时反映进所有矿山的季度实现价，缓冲系数为 1；实际 0.48（泰利森月度指数＋股东折扣）与 0.99（PLS CIF）。**缺「价格有多个」这一层，就无法解释为何指数跌 31% 而 Greenbushes 实现价只跌 6.8%、EBITDA 率反而从 80% 升到 83%。**
- **若成本只有一个口径**：则「跌穿成本线」可被判真或判伪；实际同一季 PLS 在 FOB 下是 5.51 倍、在 CIF（含 5% 州权利金＋1% 原住民＋5% 私人权利金）下是 3.51 倍。**缺口径这一层，「成本线附近的判断」就只能给一个数而不是 1.37 倍的区间。**
- **若跨周期假设不存在**：则 2026-10 作出最终投资决定的 P2000（假设长期 SC6 1,620 美元、IRR 29.5%、2029 年首矿）与 2026-09 的 Kathleen Valley 扩建无从解释——**恰恰是最紧的那家（≈成本线）在扩产翻倍**，这是本期最反直觉处，缺它就整体不成立。
- **若中国云母的收缩由价格解释**：则辉石端在同样价格下也应收缩；实际辉石 +64%、盐湖 +59%、回收 +63%，只有云母负增长，而它对应的四条原因（证照、锂渣、设备、环保）逐条可归属、无一为价格。
- **若把退出发生在矿端**：则应看到矿山永久关停；实际看到的是雅保 Kemerton（转化厂）与 Mt Cattlin（矿山，2025-03，且原因表述为资本保全）；中国境内未检索到任何永久退出，扩产项目全部按期或提前。
