## 标的卡

- 所属大类：A 资源 / 大宗商品
- A 类主链条假设（待 Phase 2 实证，照抄不算完成）：

  ```
  产能决策 → 建设/生长时滞 → 供给释放 → 库存缓冲 → 价格 → 反身性影响下一轮产能决策
  ```

- 本篇的检验方向（不在此处下结论，留待 Phase 2 逐环核对）：黄金的「库存缓冲」与其余 A 类品种性质不同——库存不是待售的中间品，而是被 45% 量级的首饰与官方储备锁住的存量；「产能决策 → 供给释放」的时滞不是 12—24 个月量级，而是 5—10 年级别。若两条成立，假设中「供给释放 → 价格」这一环在黄金上近乎断裂，主链条需要改写。

## 钩子

- **类型：A 方向翻转**（价格与供给的符号反向：涨价的通道本该放量，实际总量减少）
- 一句话：**2025 年金价比上年涨了 43.8%，全球供到市场上的金子只多了 40.4 吨；到 2026 年三季度，价格同比还在涨 23.3%，总供给反而比上年同季少了 14.6 吨——涨价没有把金子变多。**（另有跨窗口幅度参照：2024 年均价 2,386.2 美元 → 2026Q3 季均 4,262.2 美元，+78.6%，只单独说明价格幅度，不与供给增速同句）
- 层级自检：属「性质的问题」，不属「量的分解」。判据——本钩子的答案必须逼出一个机制（为什么两条通道都不响应），而不是把一个总数拆成三个分项就结束；分项拆解只是答案的第一层，第二层「为什么不被抹平」必须落到存量结构与资本流向上才闭合。
- 对照淘汰记录：曾考虑把「全球金饰消费 −17% 而需求金额创新高」作钩子，判为低层级（量的分解：吨数 × 均价 = 金额，拆完即止，逼不出机制），降级为正文 §五 的算术样板。

## 答得圆满预检

钩子翻译成的算式：

```
总供给变动 = 矿产金变动 + 回收金变动 + 生产者净对冲变动
供给价格弹性 = 总供给变动% ÷ 均价变动%
```

| 算式项 | 来源层级 | 可得性 |
|---|---|---|
| 2024 / 2025 年度矿产金、回收、对冲、总供给 | L1（世界黄金协会《全球黄金需求趋势 2025 全年》表 1，逐项到小数点后一位） | ✓ 已取到 |
| 2024 / 2025 LBMA 年均价 | L1（同上） | ✓ 已取到 |
| 2025Q3—2026Q3 五个季度的同一组分项 | L1（同上，2026-11-03 发布） | ✓ 已取到 |
| 矿产金口径的独立第二源 | L0/L1（USGS《矿产品摘要》2020/2022/2023/2024/2025/2026 版原表，含 2018—2025 逐年值与储量） | ✓ 已取到，且两年增速独立成立 |
| 矿端「不响应」的公司侧证据（现金流去向、投产时点、产量指引未上修） | L1（纽蒙特 2026Q3 业绩公告与电话会，2026-10-22） | ✓ 已取得，需标注管理层口径 |
| 回收不响应的机制证据（持有结构、存量分解） | L1 缺原始页面；地上存量仅有转引值 | △ 量级可用，精确值列入缺口 |
| 中国境内供给（国内原料产金 −14.62%）与结构置换 | L1（中国黄金协会统计，经新浪财经/协会官网全文转载） | ✓ 已取到 |

**预判结论：能闭合。** 承重结论（供给弹性 ≈ 0.018、三条通道逐项与官方总量精确相加）由 L1 表内数字自算，输入全部可列；机制层第二环（为什么不扩产）有公司披露支撑；「存量/流量比」这一项只用一个量级比值，且已把口径来源降级为转引并登记缺口——不承载核心结论，只承担解释功能。
