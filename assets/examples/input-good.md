# 合格输入示例

汇集了对分析与产出质量有实质帮助的输入形态。

---

## 例 1：带反直觉现象（最优输入）

```
帮我分析生猪养殖的需求端和产业链运行逻辑。
我最想搞懂的是：能繁母猪已经砍到 3602 万头了，为什么猪价还在跌？
```

**为什么合格**：
- 标的边界明确（生猪养殖，不含屠宰与肉制品）
- 提供了现象（砍产能但价格还跌），直接给出主线
- Phase 1 可以反向倒推机制，省去挖掘成本

---

## 例 2：明确划定边界

```
分析大陆晶圆代工的成熟制程（28nm 及以上），不含存储和先进制程，
也不含设备与材料环节。
```

**为什么合格**：
- 用「不含」显式排除了相邻环节
- 避免把整个半导体行业塞进来导致分析失焦

---

## 例 3：指定了需要反驳的说法

```
看看现制茶饮（15 元以下价格带）。
我想验证一个说法：都说茶饮是「消费降级受益」，但门店数涨的同时闭店数也在涨。
```

**为什么合格**：
- 给出了具体的流行说法与质疑角度
- 迫使分析必须做检验而不是复述

---

## 例 4：未指定行业（走自动选题）

```
下一个分析什么？给我一个没分析过的行业。
```

Skill 的处理：
1. 走 Phase 0.2 自动选题，五维打分后在 `0-frame.md` 留痕
2. 直接执行，**不向用户确认**
3. 若首选题目的数据可查性校验失败，自动换题并在台账注明

---

## 例 5：指定形态与复用 SOP

```
用已有 SOP 出一期晶圆代工的速览，更新到最新一期数据。
```

Skill 的处理：
1. 查 `domain-playbooks/` 是否有该行业 SOP
2. 有时效检查（月度 >45 天需重新取数）与反例检查
3. 使用 brief 模板产出，**篇幅控制在 800—1200 字**
4. 首次分析不得使用此形态（必须出长文并完成 SOP 沉淀）
