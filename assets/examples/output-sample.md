# 端到端执行示例

> 展示七个阶段如何串起来，**以及如何退回**。
> 数据为占位示意，实际执行时全部替换为当期现场取证结果。

---

## 输入

```
target: 生猪养殖（不含屠宰与肉制品）
phenomenon: 能繁母猪砍到 3602 万头，为什么猪价还在跌
form: longform
```

---

## 执行轨迹

### P0 选题与边界（10 min）

- 边界：养殖环节，显式排除屠宰、零售、进口
- 归类：A 类（资源/大宗）。主链条假设 = 产能决策 → 时滞 → 供给释放 → 库存缓冲 → 价格
- 钩子：「猪少了 10.7%，肉却多了 3.2%」
- 执行 `init-analysis.py` 生成本期目录

### P1 需求端（关键一役）

- 四问：① 谁付钱 = 居民家庭 ② 为什么现在付 = 日常餐饮刚性采购 ③ 支付能力由什么驱动 = 居民可支配收入与餐饮支出占比 ④ 替代 = 禽肉/牛羊/水产
- **替代效应量价对照**：禽肉产量 +9.3% ↑，禽肉价格 →（未跌）
  → 判定「**不是**需求转移，是禽肉自身供给扩张」
  → 排除流行解释，把主线推回供给端
- 需求三因子：人口 → 人均消费量 → 无显著变化 → **顶格写明「需求端不构成当期主要变量」**

### P2 链条与利润池

- 链条：祖代 → 父母代 → 仔猪 → 育肥 → 屠宰 → 零售
- 集中度：养殖端分散（CR5 <15%），屠宰端相对集中
- 议价权：养殖端无议价权（同质化活体商品，无处备库存）
- 主链条校验：**假设成立**（确为时滞型），但发现假设漏了「库存/冻品」一环 → 补进主链条
- 利润池：当期在养殖端的下游（屠宰与零售留存稳定，养殖端承担全部波动）

### P3 机制考古 ★

- **杠杆**：能繁母猪 → 商品猪出栏的 10—13 个月生物时滞
- **准入三问**：独有性 ✓（生物繁殖周期是农业独有）；可量化 ✓（月数 + 幅度）；当期性 ✓
- **对冲变量三层**：PSY/MSY 效率 +1.73%、出栏均重 +1.77%、冻品库容投放
- **多层乘法分解**：
  ```
  实际供给变动 = 表观存栏 −10.7% × (1+1.73%) × (1+1.77%) ≈ −7.6%
  ```
- **反向验证**：自算出栏 +1.41% vs 官方 +1.4%；自算产量 +3.20% vs 官方 +3.2% → **闭合**
- **历史实证**：取上一个完整猪周期的对应区间做回测
- **反例**：规模化率突破某阈值后散户行为模型失效；疫病导致非正常去化

### P4 校验（触发回路 A）

- 逐条过三重验证
- **发现一处不通过**：某环节效率数据来自 L2 商业数据商，样本仅覆盖规模化猪场 → 补标「样本偏向规模场，散养实际效率更低」后放行
- 另一处：媒体援引的压栏规模 → 无法溯源 L0—L2 → **判定删除**，进入「无法成立的结论登记表」

### P5 成稿与审校

- 产出顺序：数据表 → 证据索引 → 领域分析 → 审校意见 → 正文
- 十节骨架 + 十二项跟踪信号表（A/B/C 三桶）
- **审校挑出 4 个问题**（≥3 达标）：① 第五节类比空泛须量化 ② 某处口径未标注 ③ 反证阈值不够具体 ④ 一处使用了「大概率」
- 措辞终检：全量扫描，模糊词计数 0、自谦表述计数 0

### P6 SOP 沉淀

- 落盘 `domain-playbooks/commodities-agri-hog.md`
- 九要素齐全
- 定级：**Draft**（初次沉淀，不得跳级）
- 失效条款 3 条：数据源停更 → 降 Draft；连续 2 期证伪 → 主链条作废；规模化率阈值触发 → 散户行为模型暂停适用
- 台账追加一行

## 一条退回的真实案例

假设在 P4 发现：多层乘法分解与官方数据偏差 8%（>5% 阈值）。

处理顺序：

```
1. 禁止调整系数凑结果
2. 逐层回查数据源与口径
3. 发现是「出栏均重」使用了全口径，而官方配比是样本口径
4. 回到 P3 重做该层（不是补数据，是重做这一层）
5. 重新闭合后再次进入 P4
```

**关键点**：在 P4 补一个数据把它救回来 = 打补丁，明令禁止。
