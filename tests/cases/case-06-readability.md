## 6A：旧稿重写（正文里还留着底稿编号）

### 输入

```
把 产出/碳酸锂/02-展开-矿端面对的不是一个价/正文.md 按现行规范重写。
```

### 前置条件

- 现存正文里有 `D501`、`C504`、`【事实】`、`【外部】` 等编号与标签
- 数据表与证据索引完整，编号体系不变
- 该篇已有 10 节结构，本次只改表达形态，不换结论

### 期望轨迹

1. **5.2 口述**：先合上数据表，把该节讲一遍（留痕在 `审校意见.md`，注明「已走口述稿」）
2. **5.3 双轨引用**：正文引用改为 `（IGO 季报，2026Q3）` 形态；四类内容改用措辞区分
3. **5.5 ④**：在 `正文.md` 末尾生成「数字与出处对照表」，逐行覆盖正文全部数字
4. **5.6 门禁**：跑 `readability-check.py`，一票否决两项为 0，软指标超线 ≤3
5. **5.7 审校**：抽查 5 行附录，能回查到 `数据表.md`

### 验证项

| # | 断言 | 检查方式 |
|---|---|---|
| E1 | 正文 `D\d+` 出现次数为 0 | `readability-check.py` R6 |
| E2 | 正文 `【…】` 标签出现次数为 0 | `readability-check.py` R7 |
| E3 | 正文存在「机构 + 期间」形态的引用，且句末而非句首 | 抽查 5 处 |
| E4 | 文末有「数字与出处对照表」，四列齐全 | 读 `正文.md` 尾部 |
| E5 | 附录行数 ≥ 正文数字个数（允许合并同一数字的重复出现，需在表内注明） | 脚本统计 + 人工核对 |
| E6 | 段落中位 ≤90 字、单句成段 ≥30%、均句长 ≤55 字 | `readability-check.py` R1—R3 |
| E7 | 旁白 ≥0.6 处/千字、设问 ≥2 个 | `readability-check.py` R8—R9 |
| E8 | 开篇前 700 字数字 ≤24 个、首表 ≥600 字 | `readability-check.py` R10—R11 |
| E9 | 关键换算算式在正文里（三行以内） | 读第四节 |
| E10 | 结论、证据、缺口与重写前一致，未因改版删数据 | 逐节对照旧稿 |

**一票否决**：正文残留任何编号或标签；附录缺失或不能回查；为了让句子变短而删掉数字、删掉口径限定或删掉反证条件。
