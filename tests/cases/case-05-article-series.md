# Case 05：文章集组织与选题顺序（v1.3.0）

> 本用例分三个子场景，分别守护**冷启动优先级**、**目标不具体时的去重换视角**、**排序软约束**。
> 另设一组通用断言，守护 **S1→S6 顺序不可跳步** 与 **索引写回闭环**。

---

## 5A：冷启动（目标不具体 + 该行业无任何既有研究）

### 输入

```
分析一下现制茶饮这个行业。
```

### 前置条件

- `产出/现制茶饮/` 不存在；总台账注册表无该行业；无任何历史产出
- 目标只到行业名，无 phenomenon / subdirection / perspective
- 该行业存在多个候选开篇：加盟商单店模型、原料供应链、外卖平台抽佣、门店数口径

### 期望轨迹

1. **S1** 建立「现制茶饮」文章集与 `_系列索引.md` 骨架
2. **S2** 三源检索（总台账注册表 / 本集索引 / 产出目录）→ 三处皆空 → 判定**冷启动**
3. **S3** 判定目标**不具体**
4. **S4** 走 **S4-C 基础逻辑开篇**：选「最容易理解 + 最为关键」的基础逻辑，两类判据同时满足
5. **S5** 定为集内第 01 篇（默认由浅入深，此处无冲突）
6. **S6** 回写本集索引与总台账注册表
7. 之后进入 Part II 单篇质量门禁，写作风格与五件套不变

### 验证项

| # | 断言 | 检查方式 |
|---|---|---|
| E1 | S1—S6 按序执行并留痕，无跳步 | 读 `0-frame.md` §文章集与组织 |
| E2 | S2 三源检索均有结论，已覆盖清单四项列全（含「空」） | 读 `0-frame.md` |
| E3 | S3 判定为「不具体」，S2 判定为「冷启动」 | 读 `0-frame.md` |
| E4 | S4 分支标记为 **S4-C**，不是 S4-A / S4-B | 读 `0-frame.md` |
| E5 | 第 01 篇选题同时满足「最容易理解」与「最为关键」，两类判据各自写出依据 | 读 `0-frame.md` §S4 理由 |
| E6 | 开篇不是冷门视角、不以需先懂行业术语的环节切入 | 读正文首段 |
| E7 | 集内序号为 `存档-初稿-批文放量击穿进口定价/`，不是沿用全局流水号 | 列目录 |
| E8 | `_系列索引.md` 已建立且 §篇目表有第 01 篇 | 读索引 |
| E9 | 总台账 §文章集注册表新增「现制茶饮」一行 | 读台账 |

## 5B：已有文章集 + 目标不具体（去重换视角）

### 输入

```
继续写宠物医疗。
```

### 前置条件

- `产出/宠物医疗/` 已存在，`01-开篇-<标题>/` 与 `01-开篇-能拿证的不一定能供货/` 两篇
- 索引 §已覆盖清单已登记：子方向「批文供给节奏」「持证资格结构」；视角「名义供给与可交付供给分离」；生活入口「宠物医院年度疫苗账单」
- 目标不具体（无 phenomenon / subdirection / perspective）

### 期望轨迹

1. **S1** 定位已有文章集，读取 `_系列索引.md`
2. **S2** 三源检索 → 已覆盖清单非空 → 判定**已有研究**
3. **S3** 判定目标**不具体**
4. **S4** 走 **S4-B 去重换视角**：不重复原主题，从未覆盖处选新子方向或新视角，并说明与已有篇的关系
5. **S5** 排序归位；**S6** 回写索引

### 验证项

| # | 断言 | 检查方式 |
|---|---|---|
| E10 | S2 判定为「已有研究」，S4 分支标记为 **S4-B** | 读 `0-frame.md` |
| E11 | **未走 S4-C**、未重复基础逻辑开篇 | 读 `0-frame.md` |
| E12 | 新子方向与已覆盖清单中任一项都不同（不是换个说法重讲） | 比对索引 §已覆盖清单 |
| E13 | 生活入口未复用已登记的「宠物医院年度疫苗账单」 | 读正文首段 |
| E14 | 写出了与已有篇的关系，且落到具体篇号（承接/并列/递进/补反例） | 读 `0-frame.md` + 索引 §篇目表 |
| E15 | 集内目录名为 `02-展开-<标题>/`（集内递增 02），不是全局第 04 期 | 列目录 |
| E16 | 索引 §已覆盖清单已追加本篇新占用的子方向 / 视角 / 生活入口 | 读索引 |

## 5C：排序软约束（内容价值优先）

### 输入

```
给碳酸锂文章集再写一篇，按由浅入深排在第三篇。
```

### 前置条件

- 碳酸锂文章集已有第 01 篇（三个环节都不减产 / 渠道去库归因）
- 按「由浅入深」硬排第 02、03 篇，会出现：为凑层次必须选一个低价值主题，或把当期性最强的高价值主题推后
- 存在一个当期性强的主题，只在当前时点成立

### 期望轨迹

1. S1—S4 正常执行，选定候选主题
2. **S5 价值校验**：识别「由浅入深」与内容价值冲突
3. 调整顺序或更换更合适的主题，**不把排序当硬约束**
4. 在索引 §排序说明 写明调整理由
5. S6 回写索引

### 验证项

| # | 断言 | 检查方式 |
|---|---|---|
| E17 | S5 做了价值校验，且明确写出「由浅入深为软约束」 | 读 `0-frame.md` |
| E18 | 出现顺序调整或主题更换，不是为了维持递进外观而硬排 | 读索引 §篇目表 + §排序说明 |
| E19 | 调整理由写明：按递进会怎样带偏方向，或为何此处必须先写 | 读索引 §排序说明 |
| E20 | 高价值 / 当期性主题未被推后或删掉 | 读索引 §篇目表 |
| E21 | 未塞入凑数篇目 | 读索引 §待覆盖方向 |

## 一票否决项

任一出现即判定本用例失败：

1. 先定子方向、后做 S2 检索（顺序倒序）
2. 目标不具体且已有研究，却重复原主题或重走 S4-C 开篇
3. 冷启动选了冷门 / 需先懂术语的角度作第 01 篇
4. 为维持「由浅入深」把高价值主题推后或塞入凑数篇目
5. S6 索引未回写就进入 P1
6. 集内序号沿用全局流水号
