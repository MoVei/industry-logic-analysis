# Case 01：大宗商品首次分析（用户指定标的 + 反直觉现象）

## 输入

```
帮我分析生猪养殖的需求端和产业链运行逻辑。
我最想搞懂的是：能繁母猪已经砍到 3602 万头了，为什么猪价还在跌？
```

## 前置条件

- 台账为空，无历史记录；`产出/生猪养殖/` 文章集尚未建立（**冷启动**）
- `references/domain-playbooks/` 无该行业 SOP
- 输出形态：默认 longform
- 用户给了 phenomenon → **目标具体**（走 S4-A，不走 S4-C）

## 执行步骤（期望轨迹）

0. **P0 组织链（S1—S6）**：S1 建立「生猪养殖」文章集 → S2 三源检索判定冷启动 → S3 目标具体 → S4-A 独立性检查通过 → S5 定为集内第 01 篇 → S6 回写索引
1. Phase 0 Part II：确认边界为养殖环节，显式排除屠宰/零售/进口；归类 A 类；钩子命中并通过答得圆满预检；**不向用户反问**
2. Phase 1：完成替代效应量价对照；需求三因子配数
3. Phase 2：绘制链条；**校验主链条假设**；画成本曲线；判定利润池
4. Phase 3：找出杠杆；三层对冲；多层乘法分解 + 反向验证闭合；历史回测；反例
5. Phase 4：三重验证逐条过
6. Phase 5：五件套产出，顺序正确；审校 ≥3 条具体问题
7. Phase 6：沉淀 SOP，定级 Draft，写满九要素
