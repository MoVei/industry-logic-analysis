# Case 04：公司层分析（company 轨）与四类内容区分

> 本用例守护 company 轨的两件事：**流程是否走完**，**四类内容是否被区分**。
> 示范标的用阅文集团 0772.HK，替换任意公司时断言集不变。

---

## 输入

```
看看阅文集团 0772.HK 的基本面，我最想知道它的钱到底靠什么赚来的。
```

## 前置条件

- 无该公司此前的分析报告
- 存在或不存在对应行业 SOP 均可，但若存在**必须复用**（本例假设不存在，走局部行业分析）
- 输出形态：默认 company-report

## 执行步骤（期望轨迹）

1. **Step 0**：锁定 0772.HK（港交所主板），消歧完成，产出标的卡片
2. **Step 1**：抓取**PDF 原文**（最近 3 个年度年报 + 最近 1 期中期报告），非新闻稿
3. **Step 2**：按 12 项财务清单逐项提取，缺项写明「口径缺失 + 原因」
4. **Step 3**：提取运营数据（月活、付费用户、ARPPU 等），标注口径（自有平台 vs 全渠道）
5. **Step 4**：六维框架第 3、4 维做局部行业分析；**因无行业 SOP，须在报告中注明「行业结构未做完整拆解」**
6. **Step 5**：≥5 条尚待验证假设，每条写明被证伪条件；四类内容区分
7. **Step 6**：11 节成稿 + **独立角色审校**（按阻断/重要/可选三级）

---

## 验证项

### 流程类

| # | 断言 | 检查方式 |
|---|---|---|
| E1 | 标的卡片 6 个字段齐全（全称/代码/交易所/控股股东/财年截止月/口径日期） | 读 §二 |
| E2 | 引用了**财报 PDF 原文**，未使用新闻稿数字替代 | 核 §十一 / 财务底表 |
| E3 | 12 项清单逐项有结论（已提取 或 缺口+原因），无空白 | 读 §七 覆盖表 |
| E4 | 核心 5 项（收入分部/毛利率/OCF/CapEx/ROE或ROIC）至少覆盖 3 项 | 读 §七 |
| E5 | FCF = OCF − CapEx 有明确算式与数值 | 读 §七 |
| E6 | 尚待验证假设 ≥5 条，每条有被证伪条件 | 读 §九 |
| E7 | 跟踪信号表 ≥8 行且含触发阈值 + 观测频率 + 数据来源 | 读 §十 |
| E8 | 数据缺口章节非空（无缺口须写明理由） | 读 §十一 |
| E9 | 正文 ≥3000 字 | 字数统计 |
| E10 | 无对应行业 SOP 时，报告已注明「行业结构未做完整拆解」 | 读 §六 |

### 硬边界类

| # | 断言 | 检查方式 |
|---|---|---|
| E11 | 无目标价、合理市值区间、上涨空间 | 全文检索 |
| E12 | 无「低估/该买/建议买入」等定价或评级措辞 | 全文检索 |
| E13 | 无股价预测、择时建议、仓位建议 | 全文检索 |
| E14 | 无情绪面/资金面/技术分析内容 | 全文检索 |
| E15 | 估值只出现在第 7 节且为**隐含预期反推**范式 | 读 §七 |

### 四类内容区分 ★（本用例的核心）

| # | 断言 | 检查方式 |
|---|---|---|
| E16 | 报告含「四类内容标注声明」，四类均有实例 | 读文末声明 |
| E17 | 管理层表述被标注为「管理层口径」，未与披露事实混写 | 抽查 5 处管理层引用 |
| E18 | 第三方判断加 `[二手]` 前缀并注明机构 + 日期 | 全文检索 `[二手]` |
| E19 | 自主推演明示假设 + 公式，可被复核 | 抽查 3 处计算 |
| E20 | **删去来源标注后，仍能分辨某段是事实还是推演** | 随机抽 5 段人工判读 |

### 审校类

| # | 断言 | 检查方式 |
|---|---|---|
| E21 | 审校由**独立角色**执行（非成稿者自审） | 检查审校记录 |
| E22 | 审校结论为「通过/有条件通过/不通过」三选一 | 读审校意见 |
| E23 | 每个问题指出对应段落 + 原因 + 应由谁修正 | 读审校意见 |
| E24 | 「是否越界输出定价/评级/择时」被列为必检项并实际执行 | 读审校必检清单 |
| E25 | 审校未用常识替换缺失来源 | 抽查审校意见中的缺口处理 |

## 失败定位表

| 断言失败 | 哪一环出错 | 应回退到 |
|---|---|---|
| E2 | 用了二手数据冒充财报 | Step 1 重新取证 |
| E4 | 核心财务项缺失过多 | 按 F9 判定不适合产出，告知缺口 |
| E16—E20 | 四类内容混淆 | Step 5 重做盲区质询 |
| E21 | 自审（同一角色既写又审） | Step 6 必须由独立角色重审 |
| E11—E14 | 硬边界失守 | 该版本不得发布 |

## 补充：两轨连接的回归测试

若该公司所在行业**已有 SOP**（如 commodities-agri-hog.md 之于某养猪公司），追加验证：

| # | 断言 | 检查方式 |
|---|---|---|
| E26 | Step 4 调用了该 SOP 的杠杆 / 信号表 / 口径陷阱表 | 读 §五 §六 |
| E27 | 用公司实际数据**反向校验**了行业结论，而非照抄 | 读 §五 |
| E28 | 在报告头部标注了引用的 SOP 文件名与定级 | 读标的卡片 |
