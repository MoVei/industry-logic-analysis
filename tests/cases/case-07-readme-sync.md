# Case 07：README 同步（v1.6.0）

> 守护一件事：**产出变动后 README 必须变，且变化可被脚本抓到**。
> 本用例覆盖四种最常见的变动类型：新增篇目、目录改名、旧稿替换、新建集。

---

## 7A：已有集新增一篇

### 输入

```
给黄金这个集写第二篇，方向：央行购金到底还能撑多久。
```

### 前置条件

- `产出/黄金/` 已有 `01-开篇-金价涨四成只多四十吨/`
- README 黄金小节写「已收录 1 篇」，篇目表只有第 01 篇

### 期望轨迹

1. **S6 ①** 本集索引追加第 02 篇（状态「在写」）
2. **S6 ②** 总台账注册表「已收录篇数 1 → 2」
3. **S6 ③** README 黄金小节「已收录 2 篇」；篇目表加一行，状态「在写」，一句话留「待定稿」
4. **P5 定稿** 状态改「已成稿」，补一句话与三个直达链接
5. 收尾跑 `check-readme.py`，退出码 0

### 验证项

| # | 断言 | 检查方式 |
|---|---|---|
| E1 | README 黄金小节篇数为 2 | 读 README 小节标题 |
| E2 | 篇目表出现第 02 篇行，含正文 / 数据表 / 审校三个链接 | 读 README |
| E3 | 状态字段最终为「已成稿」 | 读 README |
| E4 | 「全部产出目录」树含 `02-展开-<标题>/` | 读 README 目录树 |
| E5 | `check-readme.py` 返回 0，C1—C4 全过 | 脚本 |

**一票否决**：写了文章但 README 篇数没变；篇目表加了行但链接指空或指向不存在路径。

## 7B：目录改名（正文标题修订）

### 输入

```
黄金第 02 篇的正文首行标题改成「央行买金是真的，但它一年只买一千吨」，其余不动。
```

### 前置条件

- 目录名原为 `02-展开-央行购金还能撑多久/`
- README 与索引都已按旧目录名登记

### 期望轨迹

1. 用 `git mv` 改目录名为 `02-展开-央行买金是真的但它一年只买一千吨/`（D24：标题取自正文首行）
2. 本集索引「目录」列同步
3. README 三个直达链接与目录树同步
4. 收尾跑 `check-readme.py`

### 验证项

| # | 断言 | 检查方式 |
|---|---|---|
| E6 | 旧目录名在 README 与索引中均已不存在 | grep 旧名 |
| E7 | README 三个链接都指向新目录且文件存在 | `check-readme.py` C2 |
| E8 | 索引「目录」列与新目录名一致 | 读索引 |

**一票否决**：只改目录不改 README（断链在页面上不报错，等同于文章消失）。

## 7C：旧稿被替换

### 输入

```
宠物医疗第 01 篇按 v1.5.0 重写，旧稿留档。
```

### 前置条件

- 现役稿 `01-开篇-能拿证的不一定能供货/`，初稿已在 `存档-初稿-批文放量击穿进口定价/`

### 期望轨迹

1. 旧现役稿改为 `存档-初稿-<旧标题>/`，**不占序号**
2. 新稿沿用 `01-开篇-<新标题>/`
3. 索引记 `01R` 指向新目录
4. README：篇数**不变**（存档不计入）；现役行链接改指新目录；补一行 `存档-` 留痕（不作数据来源）

### 验证项

| # | 断言 | 检查方式 |
|---|---|---|
| E9 | README 宠物医疗仍为「已收录 1 篇」 | 读 README |
| E10 | 存档目录在 README 有留痕行，且未计入篇数 | 读 README + `check-readme.py` C3 |
| E11 | 索引出现 `01R`，指向新目录 | 读索引 |

**一票否决**：把重写稿当新的一篇、篇数 +1。

## 7D：新建文章集

### 输入

```
分析一下光伏硅料这个行业。
```

### 前提

- `产出/光伏硅料/` 不存在

### 期望轨迹

1. S1 新建集与 `_系列索引.md`
2. S6 ③ README 新增一个小节：集名 + 「已收录 1 篇」+ 系列主线一句话 + 篇目表 + SOP 链接（若有）
3. 「全部产出目录」树加该集
4. 收尾跑 `check-readme.py`

### 验证项

| # | 断言 | 检查方式 |
|---|---|---|
| E12 | README 出现该集小节且含 `_系列索引.md` 链接 | `check-readme.py` C1 |
| E13 | 目录树含该集 | 读 README |

**一票否决**：集建了但 README 里查不到（C1 失败）。

---

## 通用断言

| # | 断言 |
|---|---|
| G1 | 所有变动在**同一次任务内**回写 README，不留到下次补登 |
| G2 | 「一句话」取自该篇钩子或杠杆，不写成宣传语 |
| G3 | 目录改名一律 `git mv`，历史可追 |
| G4 | `check-readme.py` 非 0 即任务未完成，不写「已完成」 |
| G5 | 只有脚本核对，没有脚本生成：README 内容仍由人写，脚本只判一致性 |
