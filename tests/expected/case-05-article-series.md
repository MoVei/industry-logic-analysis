# Case 05 期望输出：文章集组织与选题顺序

> 本文件是 `case-05-article-series.md` 的期望判定，用于回归比对。
> 判定的是**组织与选题流程**，不改写正文、不评判词句。

---

## 5A 冷启动 · 期望判定

| 项 | 期望值 |
|---|---|
| S1 | `产出/现制茶饮/` 新建；`_系列索引.md` 由模板生成 |
| S2 | 三源结论：总台账注册表「未登记」/ 本集索引「不存在」/ 产出目录「0 个」→ **冷启动**；已覆盖清单四项均写「空」 |
| S3 | **不具体** |
| S4 | **S4-C 基础逻辑开篇** |
| 第 01 篇选题 | 同时满足：① 一段生活场景即可入场、不需行业术语（最易理解）；② 是后续所有子方向的共同前置（最为关键）。两类判据分别在 `0-frame.md` §S4 理由中写出依据 |
| S5 | 集内第 01 篇，默认由浅入深，无冲突 |
| S6 | 索引 §篇目表出现第 01 篇（状态「在写」→ 成稿后「已成稿」）；总台账注册表新增一行 |
| 集内序号 | `01-开篇-<标题>/`，**不是**全局第 04 期 |

**一票否决**：S4 标成 S4-A / S4-B；第 01 篇为加盟商单店模型、外卖抽佣等需先讲清基础的冷门环节，且未说明它为何是共同前置；选了只满足一类判据的角度。

## 5B 已有研究 · 去重换视角 · 期望判定

| 项 | 期望值 |
|---|---|
| S1 | 定位已有 `产出/宠物医疗/`，读取已存在的 `_系列索引.md` |
| S2 | 三源结论：注册表「已登记」/ 索引「存在，2 篇」/ 产出目录「2 个」→ **已有研究**；已覆盖清单四项齐全 |
| S3 | **不具体** |
| S4 | **S4-B 去重换视角** |
| 新子方向 | 不在「批文供给节奏」「持证资格结构」之内；新视角不重复「名义供给与可交付供给分离」 |
| 生活入口 | 不是「宠物医院年度疫苗账单」 |
| 与已有篇的关系 | 四选一且落到具体篇号，例如「承接 第 01 篇：把批文时钟展开到渠道端定价」，或「补反例 第 01R 篇：……」 |
| S5 / S6 | 集内 `02-展开-<标题>/`；索引 §已覆盖清单追加本篇新占用项 |
| 禁止 | 重走 S4-C 开篇；把旧主题换个说法再讲一遍 |

**一票否决**：S4 标成 S4-C；新子方向与已覆盖清单任一项重合；关系写成「相关」「延续前文」而不落篇号；生活入口复用。

## 5C 排序软约束 · 期望判定

| 项 | 期望值 |
|---|---|
| S5 价值校验 | 明确写出「由浅入深是软约束，内容价值优先」 |
| 冲突识别 | 三选一至少命中：按递进会把后续篇目带离行业主线 / 为凑层次须选低价值主题 / 高价值主题只在当前位置成立 |
| 处理结果 | 调整顺序，或更换更合适的主题；当期性强的高价值主题**未被推后**、未删掉 |
| 索引 §排序说明 | 写明调整理由：按递进会怎样带偏方向，或为何此处必须先写 |
| 禁止 | 为维持递进外观硬排；塞入凑数篇目；把「按由浅入深排第三篇」当成不可违背的硬约束 |

**一票否决**：把用户说的「按由浅入深排在第三篇」当作硬约束执行，未做价值校验；索引 §排序说明 为空。

## 全文级判定标准（三个子场景共用）

| 维度 | 标准 |
|---|---|
| 顺序 | S1→S2→S3→S4→S5→S6 依次留痕，S2 先于子方向确定，S6 先于 P1 |
| 索引闭环 | 每篇完成后本集索引与总台账注册表均已更新；下次 `--series` 能读到本篇 |
| 组织单位 | `产出/<行业>/` 为文章集；NN 为集内序号 |
| 写作规范 | 五件套齐全、顺序正确、正文无表外数字；钩子 A/B/C 硬筛、答得圆满预检、杠杆四问 + 双层结构、自算主链、多源闭环**全部照旧** |
| 硬边界 | 无目标价 / 择时 / 情绪面 / 技术分析 / 个股推荐 |
| 措辞 | 模糊词 0、自谦 / 粉饰 / 让步 0（脚本全量扫描段落 + 表格单元格） |
| 规模 | 单文件 ≤500 行 |

## 回归意义

这三个子场景守护的是 v1.3.0 组织改造最容易失效的三处：

- **5A**：冷启动时贪图「写得漂亮」，选了冷门角度开篇，系列主线立不起来
- **5B**：已有研究时图省事，把旧主题换个说法再讲一遍（重复选题最常见的来源）
- **5C**：把「由浅入深」从默认排列误读成硬约束，为形式牺牲内容价值

任一子用例失败，v1.3.0 不得发布。
