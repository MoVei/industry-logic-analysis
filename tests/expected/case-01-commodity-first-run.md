## 各部分的结构期望

### 0-frame.md

必须出现：

- 「所属大类：A」与一条**待实证**的主链条假设
- 边界四要素（覆盖 / 不覆盖 / 时间范围 / 地理范围）齐全
- 钩子 = 用户给的那句矛盾，未被替换
- 「不覆盖」中至少排除屠宰、零售之一

### 数据表.md

- ≥15 条原始数据，每条填满七列（编号/指标/数值/期间/口径/来源级别/具体报表名）
- ≥1 条派生数据，**必须填写「交叉验证（官方值）」列**
- 数据缺口表 ≥1 行且填了「尝试过的来源」
- 派生值与官方值偏离 ≤5%

### 证据索引.md

- 每条结论挂数据编号
- 「那根杠杆的证据链」三环齐全（上游变动 / 传导过程 / 下游响应）
- 「拒绝理由记录」至少有内容或明确写「无」

### 领域分析.md

P1—P4 四节均有实质内容，非模板占位。其中：

- P1 必须出现「替代效应」判定结论（不能空）
- P2 必须出现「主链条假设校验」的实际结论（写明差异或确认）
- P0 必须写明钩子类型（A/B/C 之一）与答得圆满预检结论
- P3 必须出现「准入四问」的四个答案（含第 4 问的反事实陈述）、双层结构与「反向验证」的闭合结果
- P4 必须出现逐条校验表 + **主链登记表**（≥1 条自算式含全部输入）+ **多源闭环登记表**

### 审校意见.md

- ≥3 条
- 每条含：位置 + 问题性质 + 具体改法
- 无「整体不错」类无效反馈

### 正文.md（≥3000 字）

十节齐全。逐节的结构期望：

| 节 | 必须达成 |
|---|---|
| 一 生活入场 | 真实价格/动作/地点；无提问句开场 |
| 二 纠错 | ≥2 组 ❌/✅ |
| 三 供给格局 | 集中度有数或有明确的数据缺口说明 |
| 四 那根杠杆 | 传导时长为**区间** + 敏感性测试；类比带数字 |
| 五 反直觉机制 | 多层乘法分解表 + 反向验证闭合声明 |
| 六 需求端 | 量价对照表；若需求稳定须**顶格明写** |
| 七 政策外生 | 逐条判定角色（托底/加速器/削波器） |
| 八 传导到价格 | 条件清单逐条 ✓/✗ + 依据 |
| 九 观察清单 | 信号表 ≥8 项 + A/B/C 分桶 + 共振规则 |
| 十 风险反证 | 反证清单含具体阈值 + 数据缺口表 + 要点回顾 |

## 全文级判定标准

| 项 | 标准 |
|---|---|
| 数字可追溯 | 正文每个数字都能在数据表中找到对应行 |
| 三件套 | 抽查 10 处，来源 + 期间 + 口径齐全率 = 100% |
| 硬边界 | 目标价/择时/情绪面/技术分析/个股推荐 计数 = 0 |
| 模糊词 | 全量扫描计数 = 0 |
| 自谦/粉饰/让步 | 全量扫描计数 = 0 |
| 术语 | 首次出现均配白话解释 |
| 涨跌幅符号 | 统一使用 ↑ / ↓ / → |

## 不合格红线（任一命中即判 Case 01 失败）

1. 正文出现数据表之外的数字
2. 杠杆三问有一条为否定，但仍继续产出
3. 多层分解与官方值偏离 >5% 且未回查
4. SOP 定级非 Draft
5. SOP 存在从既有产出转录的数据
6. 出现任何第〇节禁止内容
7. 审校问题 <3 条
