# Case 07 期望输出：README 同步

> 本文件是 `case-07-readme-sync.md` 的期望判定，用于回归比对。
> 判定的是**入口一致性**：产出目录与 README 是否对得上。

---

## 7A 已有集新增一篇 · 期望判定

| 项 | 期望值 |
|---|---|
| README 集小节 | 「已收录 2 篇」 |
| 篇目表 | 新增第 02 篇行，状态最终「已成稿」，正文 / 数据表 / 审校三链接齐全 |
| 目录树 | 含 `02-展开-<标题>/` |
| 集索引 | 第 02 篇行状态「在写」→「已成稿」 |
| 总台账 | 注册表篇数 1 → 2，最近更新为当日 |
| `check-readme.py` | 退出码 0，C1—C4 全过 |

**一票否决**：README 篇数与目录不符（C3）；篇目表链接指向不存在路径（C2）。

---

## 7B 目录改名 · 期望判定

| 项 | 期望值 |
|---|---|
| 目录 | `git mv` 改为 `02-展开-央行买金是真的但它一年只买一千吨/` |
| README | 三链接与目录树同步；旧名零残留 |
| 集索引 | 「目录」列同步为新名 |
| `check-readme.py` | 退出码 0（C2 断链为零） |

**一票否决**：旧目录名仍留在 README 或索引里；出现断链。

---

## 7C 旧稿替换 · 期望判定

| 项 | 期望值 |
|---|---|
| 篇数 | README 与索引均为「已收录 1 篇」，**不 +1** |
| 存档 | 旧现役稿改 `存档-初稿-<旧标题>/`；README 有留痕行，明确「不作数据来源」 |
| 索引 | 记 `01R` 指向新目录 |
| `check-readme.py` | 退出码 0（C3 篇数一致；存档不计入） |

**一票否决**：把重写稿计为新篇；存档目录被计入篇数。

---

## 7D 新建集 · 期望判定

| 项 | 期望值 |
|---|---|
| README | 新增小节：集名 + 「已收录 1 篇」+ 系列主线 + 篇目表（+ SOP 链接如有） |
| 目录树 | 含 `产出/光伏硅料/` |
| 集索引 | `_系列索引.md` 已建，篇目表 1 行 |
| `check-readme.py` | 退出码 0；C1 不再报该集未登记 |

**一票否决**：集存在但 README 无小节（C1）。

---

## 通用 · 期望判定

| 项 | 期望值 |
|---|---|
| 时点 | S6 登记行（在写）→ P5 定稿收口（已成稿 + 一句话 + 链接），两次都动 |
| 触发覆盖 | 新增 / 改名 / 替换 / 状态变化 / 一句话修订 / SOP 变动 / 新建集，七类都在 F15 清单内 |
| 生成 vs 核对 | 脚本只核对，README 正文由人写；「一句话」不得由脚本拼装 |
| 收尾判据 | `check-readme.py` 返回 0 才可写「已完成」 |

**失败基线**（v1.6.0 之前实际发生过一次）：两篇新文章写完时 README 未动，事后单独提交才补齐——C1/C4 会对这种状态直接报错。
