# 期望输出：Case 04 公司层分析

> 定义「合格的公司研究报告长什么样」的结构特征，具体数值依赖当期取证。
> 示范标的：阅文集团 0772.HK（替换任意公司时结构不变）。

## 期望产出清单

```
产出/0772.HK/第NN期/
├─ 标的卡片.md ← 或并入报告首部
├─ 财务底表.md
├─ 证据索引.md
├─ 公司分析.md
├─ 审校意见.md
└─ 报告.md              ← 最后一个写
```

产出顺序（两轨共用）：
```
财务底表 → 证据索引 → 公司分析 → 审校意见 → 报告
```

**禁止报告出现财务底表里没有的数字。**

## 各部分结构期望

### 财务底表.md

- 12 项清单**逐项成行**，每行含：项目 / 数值 / 报表出处 / 期间 / 会计口径 / 已提取或缺口
- 核心 5 项（收入分部 / 毛利率 / OCF / CapEx / ROE 或 ROIC）不得为「缺口」超过 2 项
- FCF 计算行必须写出 `FCF = OCF − CapEx` 与代入数值
- 二手数据行加 `[二手]` 前缀 + 机构名 + 报道日期
- 缺项行写明「口径缺失 + 原因」，不得留空、不得填估算

### 证据索引.md

每条含：待证命题 / 来源标题 / 来源主体 / 发布日期 / 事实发生期 / 关键内容 / 证据层级。

**注意**：发布日 ≠ 事实发生期，两者必须分列。这也是 `06-team-protocol.md` 审校必检项之一。

### 审校意见.md

按三级排序：

```markdown
## 阻断项
| 段落 | 问题 | 原因 | 应由谁修正 |
## 重要修正
## 可选改进
## 结论：通过 / 有条件通过 / 不通过
```

「结论」必须三选一明确给出，不得含糊。

### 报告.md（≥3000 字，11 节）

| 节 | 必须达成 |
|---|---|
| 一 核心洞察 | 1—3 条，每条一句话 + 一个带来源的数字 |
| 二 标的卡片 | 6 字段齐全，含报告口径日期 |
| 三 商业模式 | 说清谁付钱、为什么付、收入确认方式；**标注哪些是管理层口径** |
| 四 业务结构与增长驱动 | 分部收入表 + 分部毛利表；驱动因子拆解到**量 or 价** |
| 五 护城河与竞争地位 | 至少一项可量化的优势证据（市占率/转换成本/成本位置） |
| 六 行业空间 | 有渗透率或 TAM；**无行业 SOP 时须注明「行业结构未做完整拆解」** |
| 七 财务质量 | 现金含量 OCF/净利润 连续 3 年；FCF 带算式；ROE 与 ROIC 均给 |
| 八 主要风险 | 每条含「风险描述 + 影响路径 + 严重程度」三要素 |
| 九 尚待验证假设 | ≥5 条，每条一个**可观测**的证伪条件 |
| 十 跟踪信号表 | ≥8 行，含触发阈值 + 观测频率 + 数据来源 |
| 十一 数据缺口 | 非空；无重大缺口须写明「无重大缺口」+ 理由 |

**文末四类内容标注声明**（必须有）：

| 类别 | 本报告中的体现 |
|---|---|
| 披露事实 | 至少 5 项具体数据 |
| 管理层口径 | 至少 1 处，标明主体与时间 |
| 外部观点 | 至少 1 处，带 `[二手]` |
| 自主推演 | 至少 1 处，写明假设与公式 |

## 全文级判定标准

| 项 | 标准 |
|---|---|
| 数字可追溯 | 报告每个数字都能在财务底表/证据索引中找到对应行 |
| 三件套 | 抽查 20 处，来源 + 期间 + 口径齐全率 = 100% |
| 硬边界 | 目标价/择时/情绪面/技术分析/评级 计数 = 0 |
| 模糊词 | 全量扫描计数 = 0 |
| 自谦/粉饰/让步 | 全量扫描计数 = 0 |
| 四类区分 | 删去来源标注后仍可分辨事实与推演 |
| 内部信息 | 无路径、ID、Prompt、SQL、协作日志 |
| 篇幅 | ≥3000 字 |

## 估值的唯一合法形态

报告中**只允许出现**这种句式：

> 当前市值 X 亿元隐含未来 5 年 FCF 复合增速约 Y%；公司过去 3 年实际可实现区间为 A%–B%。
> 隐含预期高于历史可实现水平，需由 \<具体业务\> 的超额兑现来支撑。

出现下列任一表述即判失败：

- ❌ 目标价 X 元 / 合理市值区间 X—Y 亿
- ❌ 低估 / 高估 / 该买 / 有吸引力
- ❌ 上涨空间 X%

## 不合格红线（任一命中即判 Case 04 失败）

1. 报告出现财务底表之外的数字
2. 核心 5 项财务缺失 ≥2 项仍产出报告
3. 四类内容未被区分，或外部观点被写成披露事实
4. 同一角色既写又审
5. 出现任何第〇节禁止内容
6. 出现「行业 XXX 处领先地位」式无数据支撑的定性结论
7. 删除来源标注后无法分辨事实与推演
