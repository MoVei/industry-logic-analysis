# Case 08 期望输出：集索引收口检查

> 本文件是 `case-08-index-integrity.md` 的期望判定，用于回归比对。
> 判定的是**索引自身是否收口干净**：三节是否各司其职、有无重复、有无占位、与磁盘是否一致。
> 五条判定全部在 `check-ledger.py --series`，任一失败退出码 2。

---

## 8A 三节互相复制 · 期望判定

| 项 | 期望值 |
|---|---|
| S1 输出 | `❌ 子方向＝视角；子方向＝生活入口；视角＝生活入口（三节被填成同一串）` |
| 修正后 | 三节内容两两不同；生活入口为具体场景 |
| 退出码 | 修正前 2，修正后 0 |
| 其他判定 | S2—S5 不受影响，仍各自判定 |

**一票否决**：靠改几个词让三节「看起来不同」，实质仍是同一串。

---

## 8B 节内重复 · 期望判定

| 项 | 期望值 |
|---|---|
| S2 输出 | `❌ 已用生活入口 重复 1 条：<条目缩略>` |
| 修正后 | 该节 2 条，等于实际生活入口数 |
| 留痕 | 维护记录追加一行，写明回写时引入 |
| 退出码 | 修正前 2，修正后 0 |

**一票否决**：静默删条目、无留痕。

---

## 8C 占位残留 · 期望判定

| 项 | 期望值 |
|---|---|
| S3 输出 | `❌ 1 处：待成稿后回填` |
| 扫描范围 | 篇目表单元格 + 四节条目；维护记录与篇目表外叙述不参与 |
| 修正后 | 该格为实义内容，或写明「缺口：<缺什么>」 |
| 退出码 | 修正前 2，修正后 0 |

**一票否决**：换成「待补充」等近义词继续留空。

**实测校准**：光伏硅料索引第 30 行（篇目表下的说明）与维护记录里都含「待成稿后回填」字样，属修正历史；该集 S3 判定应为 ✅，不报错。

---

## 8D 索引缺失 / 篇目表空 · 期望判定

| 场景 | 期望值 |
|---|---|
| 索引缺失 + 磁盘有篇目目录 | `❌ 索引缺失，但磁盘已有 N 个篇目目录 → 须在 S1 补建并从目录回填` |
| 索引存在 + 篇目表 0 行 + 磁盘有目录 | `❌ 篇目表 0 行，但磁盘已有 N 个篇目目录` |
| 索引缺失 + 磁盘为空 | `✅ 无索引且无篇目目录：冷启动，由 S1 建骨架`（S1—S3、S5 记「索引缺失，跳过」） |

**一票否决**：把「磁盘已有篇目但索引不存在」当成冷启动放行。

---

## 8E 目录不符 · 期望判定

| 项 | 期望值 |
|---|---|
| S5 输出 | `❌ 表中有、盘上无：02-展开-旧标题；盘上有、表中无：02-展开-新标题` |
| 修正后 | 篇目表「目录」列同步，双向对齐 |
| 存档处理 | `存档-` 前缀目录不计入磁盘侧比对（宠物医疗集 2 行 / 1 个现役目录应通过） |
| 退出码 | 修正前 2，修正后 0 |

**一票否决**：只改一边。

---

## 通用 · 期望判定

| 项 | 期望值 |
|---|---|
| 输出形态 | 五条逐行列出，每条带 ✅/❌ 与具体原因；末尾给「通过 / 不通过（N 项）」 |
| 退出码 | 0 全过；2 有失败。与 `--check` 的 1（不可写）区分 |
| 与 README 检查的关系 | 并列，互不替代：`check-readme.py`（C1—C4）看入口，`--series`（S1—S5）看索引 |
| 收尾判据 | 两个都为 0 才可写「已完成」 |
| 可回归 | 支持 `--root <夹具目录>`，五条判定可在临时目录复现 |

**失败基线（v1.7.0 之前）**：碳酸锂索引「已用生活入口」第 1 与第 3 条一字不差，挂了整整一天，
直到人工读 README 才发现；当时 `--series` 会把它原样打印出来并返回 0。
