## 6A 旧稿重写 · 期望判定

| 项 | 期望值 |
|---|---|
| 正文编号（R6） | **0**（重写前为 61—153 处） |

| 引用形态 | `（IGO 季报，2026Q3）`、`（国家统计局，2026Q3 末）`；四类内容用措辞区分 |

**一票否决**：正文残留编号或标签；附录缺失或抽查 5 行有回查不到的；为缩短句子删掉数字、口径或反证条件。

## 6B 新写一篇 · 期望判定

| 项 | 期望值 |
|---|---|
| 五件套 | `数据表 → 证据索引 → 领域分析 → 审校意见 → 正文`，正文最后写 |
| 可读性结论 | 首次成稿即「通过」，不靠全局修剪 |
| 篇首元信息 | 4—6 行小表（行业／本篇角度／数据截止），与叙事分开 |
| 开篇 | 前 700 字数字 ≤24 个、无表、无编号；首表 ≥600 字 |
| 与已有篇 | 写明承接/并列/递进关系，落到第 01 篇 |
| 术语 | 首现配白话（宠物医疗篇至少覆盖：单店模型、客单价、复购率） |

**一票否决**：正文出现编号；为过门槛把句子砍成断句；四类内容无法分辨。

## 通用 · 期望判定

| 项 | 期望值 |
|---|---|
| 门槛来源 | 一律取 `08-readability-laypeople.md` §7，脚本口径不临时改 |
| 超线处理 | 只重写超线的那几节；全篇段长中位数不因修剪而低于 30 字 |
| 冲突裁决 | 可读性 vs 严谨 → 保严谨，挪位置（附录/读法说明） |
| 存量旧稿 | 不追改；索引状态不变 |
| 校准基线 | 常识四篇 0 项超线；存量产出五篇一票否决失败且超线 5—9 项 |
